# 第2天：看懂最小价值桥

**本课目标**：从经营利润走到每股价值，发现利润、现金、权益口径和股本分母错配；能够验收投研 Agent 是否把两座桥记录完整。基础层约25分钟，开发者层约20分钟。

## 先闭卷回忆

不看第1课，先用两分钟写下：

1. 派生计算为什么不能只保存最终数字？
2. 一条记录“已复核”，是否代表整份估值材料一定可继续使用？
3. 如果每股价值突然上升，你会先查公司价值，还是也会查股本分母？

今天不要求你搭建 DCF，只练一件事：看到一个每股价值时，能够沿路倒查每一步有没有漏项或口径错配。

## 10分钟白话解释

先读 [`白话术语表`](../docs/GLOSSARY.md) 中 EBIT、NOPAT、FCFF、EV、股权价值和每股价值六节。

只记两座桥：

```text
EBIT
→ 扣经营税得到 NOPAT
→ 加折旧、减资本开支、减营运资金增加
→ FCFF
```

```text
EV
→ 加现金、减债务等资本结构项目
→ 股权价值
→ 除以正确股本
→ 每股价值
```

第一座桥回答“经营利润最后留下多少可供股东和债权人共同支配的现金”；第二座桥回答“经营资产的价值中，有多少真正属于对应的普通股股东”。

任何一座桥断掉，都可能让最后的每股数字失真。模型从利润直接跳到价值，或者从 EV 直接跳到每股价值时，不要替作者脑补中间项，要让材料把桥写出来。

## 第一座桥：利润怎样变成现金

最小教学公式是：

```text
NOPAT = EBIT × (1 - 经营税率)

FCFF = NOPAT + 折旧 - 资本开支 - 营运资金增加
```

### 为什么这样加减

| 项目 | 白话解释 | 在最小桥中的方向 | 审计时要问什么 |
|---|---|---:|---|
| EBIT | 暂时不考虑利息和所得税，经营本身赚了多少 | 起点 | 是否误用了净利润、归母净利润或 EBITDA？ |
| 经营税 | 经营利润对应的税负 | 减 | 税率是实际、正常化还是内部假设？ |
| 折旧 | 以前买的设备在本期计入利润表的成本，不代表本期又支付同额现金 | 加回 | 是否只加回了真正的非现金费用？ |
| 资本开支（Capex） | 本期购买或建设长期资产实际付出的现金 | 减 | 维持经营和扩产所需投入是否被漏掉？ |
| 营运资金增加 | 更多库存、应收减去应付等经营项目占用的现金 | 减 | 增长是否需要提前备货或给客户更长账期？ |

“营运资金增加”是一个带方向的词：增加代表现金被占用，所以要减；如果营运资金减少或释放 2 亿元，公式中的这一项是 `-(-2)`，也就是给 FCFF 增加 2 亿元。

### 完整数字例子

虚构公司长河制造本年有：

| 输入 | 数值 |
|---|---:|
| EBIT | 20亿元 |
| 经营税率 | 20% |
| 折旧 | 3亿元 |
| 资本开支 | 5亿元 |
| 营运资金增加 | 2亿元 |

先算税后经营利润：

```text
NOPAT = 20 × (1 - 20%) = 16亿元
```

再把利润变成现金：

```text
FCFF = 16 + 3 - 5 - 2 = 12亿元
```

这 12 亿元不是“公司账上增加了12亿元现金”，而是在这套简化定义下，可供股东和债权人共同支配的企业自由现金流。它还要经过未来各期预测和折现，才会形成 EV。

### 为什么 16 亿元 NOPAT 不能直接冒充 16 亿元 FCFF

如果模型直接把 NOPAT 16 亿元当作 FCFF，它比逐项计算的 12 亿元多了 4 亿元：

```text
漏掉的净投入 = Capex 5 + 营运资金增加 2 - 折旧 3 = 4亿元
```

- **为什么可疑**：公司为扩产和支持销售付出了现金，模型却让这些投入消失了。
- **影响什么**：每一期 FCFF 可能被系统性抬高，后续 EV、股权价值和每股价值都要重算。
- **还不能断言什么**：不能据此说扩产是坏事，也不能判断股票高估；扩产未来可能产生很高回报，当前只确认现金流桥错误。

### 简化公式不是普遍完整答案

真实材料还可能出现摊销、资产处置、股份支付、重组费用、资本化研发、递延税、租赁或其他非现金及非经营调整。不同模型也可能从经营现金流、EBITDA 或净利润出发。

遇到这些项目时，不要机械要求所有材料长得一模一样。你要检查的是：

1. 起点利润口径是什么；
2. 每项调整为什么加或减；
3. 有没有重复计算或漏算；
4. 同一套 FCFF 定义是否贯穿正向模型、反向模型和报告表述；
5. 能否与财报现金流做交叉检查并解释差异。

材料使用不同公式不自动等于错误；定义隐藏、前后不一致或无法复算，才需要降级。

## 第二座桥：企业价值怎样走到每股价值

最小教学公式是：

```text
股权价值 = EV + 现金 - 债务

每股价值 = 股权价值 ÷ 对应的外部普通股股数
```

假设长河制造的 EV 为 200 亿元、现金 20 亿元、债务 50 亿元：

```text
股权价值 = 200 + 20 - 50 = 170亿元
```

如果对应的外部普通股为 10 亿股：

```text
每股价值 = 170 ÷ 10 = 17元
```

### 为什么 EV 不能直接除以股本

EV 是经营资产对股东和债权人的总价值。债权人对其中一部分有要求权；公司持有的多余现金等非经营资产，又可能增加普通股股东拥有的价值。因此必须先完成资本结构桥，才能得到股权价值。

真实 EV 桥常见项目包括：

| 项目 | 常见处理方向 | 为什么不能只背正负号 |
|---|---:|---|
| 现金或可确认的非经营金融资产 | 加 | 要确认是否真能归普通股股东、是否已包含在经营价值中 |
| 有息债务 | 减 | 债权人的要求权通常优先于普通股 |
| 租赁负债 | 常见为减 | 前提是经营预测与 EV 口径没有已经处理，否则可能重复扣除 |
| 少数股东权益 | 常见为减 | 合并经营数据可能包含不属于母公司普通股股东的部分 |
| 联营、长期投资等非经营资产 | 可能加 | 必须有独立价值依据，并确认对应收益没有同时留在经营预测中 |

这张表不是一套见词就套的符号规则。项目应加、应减还是已经包含，取决于 EV 的定义、经营预测范围和会计口径。正确动作是要求作者给出逐项桥，而不是让 Agent 根据项目名称自动补数。

### 分母不是“找一个股数来除”

| 股本口径 | 它通常表示什么 | 常见误用 |
|---|---|---|
| 总股本 / 已发行股份 | 公司发行过的股份总量，是否含库存股要看定义 | 未核对库存股就直接作为外部股数 |
| 流通股 | 当前可在市场流通的一部分股份 | 用它分摊全体普通股股东的股权价值 |
| 外部普通股 | 由公司之外的股东持有、与本次权益口径对应的股份 | 忽略不同股份权利或证券范围 |
| 库存股 | 公司回购后自己持有的股份 | 仍把它当成外部股东持股，导致分母偏大 |

增发会增加外部普通股；回购并形成库存股会减少外部普通股。双重上市公司还要先说清估值对象：是发行人全部普通股的股权价值，还是某一具体证券的价格等价。A 股、H 股或其他股份类别的数量、权利和换算关系不能靠名称猜。

继续使用 170 亿元股权价值：

- 用正确的 10 亿股，得到每股 17 元；
- 若错误使用 8 亿流通股，得到每股 21.25 元。

公司股权价值没有变化，错误分母却把每股结果抬高：

```text
(21.25 ÷ 17) - 1 = 25%
```

- **为什么可疑**：模型把属于全部对应普通股股东的价值，只分给了较少的股份。
- **影响什么**：当前每股输出高估 25%，更新股本后必须重算。
- **还不能断言什么**：不能据此否定 170 亿元股权价值本身，也不能据此判断证券贵或便宜。

## 好坏对照

### 桥完整

> 长河制造 EBIT 为20亿元，经营税率20%，因此 NOPAT 为16亿元。加回折旧3亿元，扣除Capex 5亿元和营运资金增加2亿元，FCFF为12亿元。该FCFF进入折现模型得到EV 200亿元；再加现金20亿元、减债务50亿元，得到普通股股权价值170亿元。估值日对应外部普通股为10亿股，因此每股价值17元。少数股东权益和租赁负债在本例均为零。

这段话把起点、每项调整、资本结构桥和分母都写出来，数字可以手工复算。

### 桥断了

> 长河制造 EBIT 为20亿元，因此自由现金流为20亿元。模型计算公司价值为200亿元，除以8亿流通股，合理价值为每股25元。

至少有四个问题：

1. EBIT 没有扣经营税；
2. 折旧、Capex 和营运资金全部消失；
3. “公司价值”没有说明是 EV 还是股权价值，现金与债务也没有桥；
4. 8 亿流通股是否对应全部股权价值无法确认。

合格判断不是“25元看起来太高”，而是：当前材料无法复算，停止使用每股输出；补齐两座桥和对应股本后重算。即使修复后仍得到25元，也不能由此直接推出股票值得买。

## 单变量实验：先预测，再计算

仍使用默认输入：EBIT 20亿元、税率20%、折旧3亿元、Capex 5亿元、营运资金增加2亿元。

先不要看答案：

1. 只把 Capex 从5亿元改为12亿元，其他不变，FCFF 变成多少？
2. 只把“营运资金增加2亿元”改为“营运资金释放2亿元”，FCFF 变成多少？
3. 股权价值仍为170亿元，只把外部普通股从10亿股改为12.5亿股，每股价值变成多少？

<details>
<summary>计算后展开答案</summary>

1. `16 + 3 - 12 - 2 = 5亿元`。Capex 多7亿元，FCFF 同方向减少7亿元。
2. `16 + 3 - 5 - (-2) = 16亿元`。营运资金从占用2亿元变成释放2亿元，相对默认案例增加4亿元现金。
3. `170 ÷ 12.5 = 13.6元`。股权价值不变，分母增加25%，每股价值由17元下降20%；不要把“分母增加25%”误写成“每股下降25%”。

</details>

实验只证明这套算式中的机械方向，不证明现实公司增加 Capex 一定毁灭价值，也不证明营运资金释放可以永久持续。

## 开发者层：验收一段投研 Agent 输出

虚构 Agent 输出如下：

> 长河制造2026年EBIT为20亿元，因此FCFF也是20亿元。公司处于扩产期，12亿元Capex和8亿元新增库存应收属于增长投入，不影响自由现金流。模型算得EV 200亿元，直接加现金20亿元后得到股权价值220亿元。公司目前总股本10亿股，但旧模板继续使用增发前8亿流通股，因此每股价值27.5元。以上计算已经验证。

这段话固定埋入四类核心问题：

1. **利润直接冒充现金**：EBIT 尚未扣经营税，更没有经过非现金项目和再投资调整。
2. **增长投入被错误忽略**：Capex 和新增库存应收会消耗当期现金；“为了增长”不等于“不影响现金流”。
3. **EV 桥漏掉债务**：只加现金，没有说明债务、租赁、少数股东权益等项目是否为零或已处理。
4. **使用旧分母**：已知总股本发生变化，模板仍使用增发前8亿股；而且“流通股”是否等于对应外部普通股没有说明。

合格的验收意见是：

> 当前每股输出**停止使用**。20亿元 EBIT 不能直接标为 FCFF；先明确经营税、折旧和全部再投资项目，逐项重算现金流。EV 到股权价值必须补齐同一时点、同一范围的资本结构桥，不能只加现金。最后使用与普通股股权价值对应的外部普通股分母，并说明增发、流通股和库存股关系。完成前不得声称27.5元已经验证。已知问题只证明当前现金流桥和每股输出失效，尚不能判断公司的扩产回报、EV 200亿元本身或证券是否高估。

### 修复后的最小记录链

| 环节 | 至少保存什么 |
|---|---|
| 利润起点 | EBIT 数值、期间、单位、经营范围和证据指针 |
| 税后经营利润 | 经营税率、性质、采用日、公式和 NOPAT |
| 现金流调整 | 折旧、Capex、营运资金及其他调整的数值、方向和依据 |
| FCFF | 完整公式、输入版本、计算结果，以及与财报现金流的差异解释 |
| EV | 使用哪组 FCFF、折现公式和计算版本得到 |
| 资本结构桥 | 现金、债务、租赁、少数股东权益和非经营资产的取值与处理 |
| 每股分母 | 证券/权益范围、总股本、增发回购、库存股和外部普通股关系 |
| 最终判断 | 使用等级、受影响输出、关闭条件和仍不能断言的内容 |

### 失败状态矩阵

| 触发条件 | Agent 应返回 | 影响 | 还不能断言 |
|---|---|---|---|
| EBIT 或 NOPAT 未经调整直接命名为 FCFF | 明确错误；停止使用当前 FCFF 与下游结果 | EV、股权价值和每股价值需重算 | 公司经营差或证券高估 |
| Capex 或营运资金缺失，材料无法判断是否为零 | 无法确认；补证据和定义 | 现金转化与结果方向不可靠 | 缺失项一定很大 |
| 正向模型和反向模型使用不同 FCFF 定义且无解释 | 口径不一致；受影响比较停止使用 | 两边结果不能直接比较 | 哪一边一定更接近现实 |
| EV 直接除以股本 | 资本结构桥缺失 | 普通股价值可能混入债权人或少数股东权益 | EV 本身一定算错 |
| 合并 FCFF 与 EV 未处理少数股东权益 | 警告、无法确认或失败，取决于金额和是否已包含 | 归母普通股价值可能高估 | 看到少数股东权益就自动减同一个数 |
| 增发后仍使用旧股本 | 明确错误；停止使用每股输出 | 每股分母失真，必须重算 | 总股权价值也一定错误 |
| 有总股本和流通股两种口径，且各自用途解释清楚 | 状态不变，不降级 | 按各自用途继续使用 | 多种股本数字天然冲突 |
| 高 Capex 有逐项证据且 FCFF 已正确扣除 | 状态不变，不降级 | 当期 FCFF 较低被如实反映 | 高 Capex 一定创造或毁灭价值 |

## 负对照：危险信号不等于自动报错

另一段输出如下：

> 长河制造 NOPAT 为16亿元，折旧3亿元，Capex 12亿元，营运资金释放2亿元，因此FCFF为9亿元。Capex较高是三条新产线的现金支出，已经在FCFF中扣除；营运资金释放来自客户预付款增加，公式按“营运资金增加”为负2亿元处理。EV为200亿元；现金20亿元、债务50亿元，租赁负债和少数股东权益均为零，因此股权价值170亿元。公司披露总股本10.5亿股，其中库存股0.5亿股；模型使用10亿外部普通股，得到每股价值17元。另列8亿流通股只用于说明市场流动性，不参与每股价值计算。

先复算 FCFF：

```text
FCFF = 16 + 3 - 12 - (-2) = 9亿元
```

这段材料里有三个看起来危险但不应自动降级的地方：

| 表面信号 | 为什么当前不降级 |
|---|---|
| Capex 高达12亿元 | 已有逐项用途并在 FCFF 中正确扣除；高投入不等于公式错误 |
| 营运资金为负数 | 含义被明确为释放现金，符号与公式一致 |
| 同时出现10.5亿、10亿和8亿三种股本 | 三者分别是总股本、扣库存股后的外部普通股和流通股，用途没有混用 |

是否可继续使用仍取决于这些数字的证据和本次用途，但不能因为“Capex高”“出现负数”或“股本数字不止一个”就直接判错。验收器必须同时会抓错误和放过合规条款。

第2行：应重算 FCFF 为16亿元，并记录营运资金从占用现金变成释放现金；这是输入变化，不是错误。其他输入的验证状态、EV 公式结构和股本记录不变，但所有依赖旧 FCFF 数值的派生结果必须重新生成。

第3行：如果“删除”代表债务字段缺失，应返回“股权价值桥无法确认”，不能把未知自动当成零。FCFF 与 EV 的计算状态、股本关系不变。

第4行：应把每股价值重算为13.6元，并使旧17元失效。170亿元股权价值及其上游 FCFF、EV 和资本结构桥状态不变。

第5行：状态不变，不降级。新增字段用途明确且没有进入价值分母；10亿外部普通股和17元每股价值保持不变。如果系统看到第二个股本数字就报警，说明它只匹配关键词，没有理解用途。

参考答案不要求逐字一致。判分看三点：是否给出具体状态，是否让依赖该输入的派生值重算，以及是否保护无关记录不被连带降级。

## 一页验收清单

- 起点究竟是 EBIT、EBITDA、净利润还是经营现金流？
- EBIT 到 NOPAT 的税率和公式是否明确？
- 折旧、Capex、营运资金和其他调整是否逐项说明方向？
- 营运资金“增加”与“释放”的符号是否写反？
- 正向、反向和报告表述是否使用同一套 FCFF 定义？
- FCFF 与财报现金流的重大差异能否解释？
- EV 到普通股股权价值的逐项桥是否完整且没有重复处理？
- 合并口径下的少数股东权益是否说明怎样处理？
- 总股本、流通股、库存股和外部普通股是否各有明确用途？
- 增发、回购或双重上市后，分母是否对应估值对象？
- 上游输入变化后，所有下游派生值是否重新生成？
- 最终意见是否写清影响、关闭条件和仍不能断言什么？

## 闯关

1. EBIT增长30%，但库存、应收和Capex增长更多。可以直接断言FCFF也增长30%吗？
   - A. 可以
   - B. 不可以

2. 模型的 Capex 字段为空，Agent 自动按零计算。最合适的判断是：
   - A. 无法确认，缺失不能静默填零
   - B. 没有数字就代表没有支出

3. 模型用合并FCFF计算EV，却完全没说明少数股东权益如何处理。最合适的动作是：
   - A. 直接通过
   - B. 要求解释EV到归母普通股价值的桥

4. 公司回购形成库存股后，每股价值应优先检查：
   - A. 输出所用分母是否剔除库存股并与权益口径一致
   - B. 研报页数

5. 材料同时列出10亿外部普通股和8亿流通股，明确前者用于每股价值、后者只说明流动性。应如何处理？
   - A. 出现两个股本数字，所以自动失败
   - B. 用途清楚且未混用，不因数字不同自动降级

6. 修正旧股本后，每股价值从17元降到13.6元，可以直接断言股票被高估吗？
   - A. 可以
   - B. 不可以；只证明旧每股输出错误

<details>
<summary>完成后展开答案</summary>

1. **B**。利润必须经过现金流桥，增长方向甚至可能不同。
2. **A**。未知不等于零；缺少关键输入时不能声称派生值已复核。
3. **B**。合并经营价值可能包含不属于母公司普通股股东的部分，但具体处理仍要结合口径判断。
4. **A**。每股结果对分母直接敏感。
5. **B**。多个口径可以同时正确，关键是定义和用途没有混用。
6. **B**。修正分母只处理了计算错误，不构成买卖或高低估结论。

</details>

## 本课边界

你现在能够解释利润怎样变成现金、EV 怎样变成每股价值，检查两座桥是否存在、口径是否一致，并为 Agent 写出包含“必须改变”和“必须不变”的验收测试。

你暂时不需要判断每一项预测的精确值，也还不能仅凭一座桥完整就判断估值正确或证券值得买。时点、币种、来源、敏感性和方法是否匹配，将由后面的课程继续检查。
