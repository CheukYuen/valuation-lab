# 七天零基础估值课程

目标：先理解价值怎样从经营和现金流产生，完成一套简化估值，再判断估值输出是否可靠、能否继续使用。

互动版入口：[`web/index.html`](../web/index.html)。互动版包含即时反馈、进度、笔记和浏览器内模型；本目录保留纯文字课程。

## 学习约定

1. 先写答案，再展开每课末尾的解释。
2. 不认识术语就查 [`白话术语表`](../docs/GLOSSARY.md)，不需要额外看书。
3. 每次计算都写输入、单位和公式；每次判断都写证据，不使用“感觉太贵”“看起来保守”。
4. `无法确认` 是合格答案；不要替材料补假设。
5. 每课含一个必做运行环节：先写计算或方向判断，再运行课里给出的命令复算。脚本提供反馈，不替你学习。
6. 每课采用 [`快速科学学习法`](../docs/LEARNING-METHODS.md)：闭卷回忆 → 新概念 → 先答后看 → 单变量实验 → 一句话输出。

## 顺序

1. 先做 [`入门测验`](PRETEST.md)，只记录基线，不查答案。
2. 按顺序完成 [`DAY-1`](DAY-1.md) 至 [`DAY-7`](DAY-7.md)。
3. 做 [`毕业测验`](POSTTEST.md)，至少答对 8/10。
4. 使用第7课模板写出一页长飞估值解释与检查结论。七个运行环节全部跑过。

## 毕业能力

完成课程后，你能够：

- 用自己的话解释估值怎样把经营假设和风险翻译成价值；
- 从 EBIT 走到 FCFF、EV、股权价值和每股价值；
- 运行并解释一个最小 DCF，说明关键假设和敏感性；
- 确认估值对象、时点、单位和每股分母；
- 把已发生事实、公司指引、外部预测、内部假设、派生计算和分析判断这六类信息分开；
- 检查利润如何变成现金；
- 找到控制结果的关键假设和终值；
- 判断方法与商业模式是否匹配；
- 给出 `可继续使用 / 带条件使用 / 停止使用`，并说明证据。

这代表你能完成和检查一套简化估值，不代表你已经能够独立预测一家真实公司的全部未来，也不代表你能据此决定买卖。
