## 10分钟白话解释

DCF是“现金流折现”：先估未来每年能产生多少自由现金，再因为等待和风险把未来现金换算成今天的价值。

```text
未来每年FCFF
→ 分别折回今天
→ 加上显性期结束后的终值现值
→ 得到企业价值EV
→ 扣净债务得到普通股股权价值
```

### 为什么未来现金要折现

今天的1亿元可以投资、可以应对风险，也已经在手里；七年后的1亿元需要等待，而且可能无法实现。因此模型用折现率表达资金时间价值和风险要求。

第`t`年现金流的现值为：

```text
第t年FCFF现值 = 第t年FCFF ÷ (1 + WACC)^t
```

这里的WACC是教学模型对经营资产整体要求的折现率。你暂时不需要推导它，但必须知道币种、风险和资本结构不同，合理WACC也可能不同。

### 显性期之后怎么办

模型不可能逐年预测到无限远，于是把详细预测结束后的现金流压缩成终值。最小永续增长公式是：

```text
终值 = 第7年FCFF × (1 + 永续增长率) ÷ (WACC - 永续增长率)
```

终值站在第7年末，还要再折回今天。公式要求`WACC > 永续增长率`；若两者相等或增长率更高，分母为零或负数，这套永续公式失去经济意义，不应强行打印结果。

## 完整示例：七年最小 DCF

虚构公司的输入全部是内部教学假设：

| 输入 | 数值 | 含义 |
|---|---:|---|
| 起点FCFF | 10亿元 | 第1年增长前的现金流基数 |
| 显性期增长 | 8% | 未来7年每年同比增长 |
| 显性期 | 7年 | 逐年列出现金流的期间 |
| 永续增长 | 2% | 第7年后长期增长假设 |
| WACC | 9% | 未来FCFF折现率 |
| 净债务 | 20亿元 | EV到股权价值的桥 |

### 第一步：预测未来FCFF

```text
第t年FCFF = 10 × (1 + 8%)^t
```

| 年 | FCFF（亿元） | 按9%折现后的现值（亿元） |
|---:|---:|---:|
| 1 | 10.80 | 9.91 |
| 2 | 11.66 | 9.82 |
| 3 | 12.60 | 9.73 |
| 4 | 13.60 | 9.64 |
| 5 | 14.69 | 9.55 |
| 6 | 15.87 | 9.46 |
| 7 | 17.14 | 9.38 |

七年显性期现值合计：

```text
显性期现值 = 67.48亿元
```

### 第二步：计算并折现终值

```text
第7年末终值 = 17.1382 × (1 + 2%) ÷ (9% - 2%)
             = 249.73亿元

终值现值 = 249.73 ÷ (1 + 9%)^7
         = 136.61亿元
```

### 第三步：从EV走到股权价值

```text
EV = 67.48 + 136.61 = 204.09亿元
股权价值 = 204.09 - 20 = 184.09亿元
```

这是明确假设下的教学结果，不是现实公司的目标价。结果保留两位小数是为了复算，不表示输入真的精确到0.01亿元。

## 五个控制杆

无论模型有多少工作表，都可以先归纳为 [`DCF的五个控制杆`](../docs/FIVE-NUMBERS.md)：

| 控制杆 | 本例 | 主要问题 |
|---|---:|---|
| 起点现金 | 10亿元 | 当前可持续FCFF是多少？ |
| 增长 | 8% | 靠销量、价格、利润率还是现金转化？ |
| 持续时间 | 7年 | 高增长能维持多久？ |
| 远期状态 | 2%永续增长 | 远期利润率、再投资与资本回报是否正常？ |
| 折现率 | 9% | 风险、币种和资本结构依据是什么？ |

敏感性表回答“合理改变一个输入，价值会怎样变化”，不回答“哪个输入正确”。

### 终值占比怎样读

本例终值现值占EV：

```text
136.61 ÷ 204.09 = 66.9%
```

这说明大约三分之二的EV依赖第7年后的远期状态，需要重点质证。它不自动证明模型失效：长寿命稳定资产可能天然有较高终值占比；变化快、竞争强的业务则更难支持遥远假设。

拉长显性期也不自动提高质量。若只是把同一条缺乏证据的增长线多画几年，远期假设只是从“终值”搬进了“明细期”。

### 终值的第二种写法：退出倍数

有些模型不用永续增长，而是给第7年一个退出倍数：

```text
终值 = 第7年FCFF × 退出倍数
```

两种写法必须互相检查，因为它们描述的是同一件事。本例的永续增长终值249.73亿元，隐含的退出倍数是：

```text
249.73 ÷ 17.14 = 14.6倍
```

反过来，如果一份材料直接选了10倍退出倍数：

```text
终值 = 17.1382 × 10 = 171.38亿元
终值现值 = 171.38 ÷ 1.8280 = 93.75亿元
EV = 67.48 + 93.75 = 161.23亿元
股权价值 = 141.23亿元
```

这个10倍隐含的永续增长率是多少？把它代回永续公式反解，得到约 **-0.91%**——也就是假设公司在第7年之后长期萎缩。

- **为什么可疑**：倍数看起来是一个“市场化”的选择，但它其实同时锁定了一个远期增长假设，而这个假设从未被写出来。
- **影响什么**：股权价值从184.09亿元降到141.23亿元，降幅23.3%；终值占比也从66.9%降到58.1%。
- **还不能断言什么**：不能说10倍一定错。若这门生意确实面临长期萎缩，-0.91%可能才是诚实的。要求的不是换一个倍数，而是**把倍数隐含的远期状态显式写出来并质证**（AUDIT `D12`）。

一份只报退出倍数、不报隐含永续增长的材料，等于把最关键的远期假设藏在了一个看起来很专业的数字后面。

### 周期公司的正常化

若今年产品价格暴涨、利润率从历史8%升至25%，把25%永久延续会显著抬高终值。检查时要问供给、价格、成本和竞争是否支持这种远期状态。

反过来，机械使用历史8%也不一定正确；业务结构真正改变时，长期利润率可以提高。正确动作是给出机制和区间，而不是把历史均值或当前峰值当作真理。

## 好坏对照

**合格表达**：

> 在起点FCFF 10亿元、未来7年增长8%、WACC 9%、永续增长2%和净债务20亿元的教学假设下，股权价值为184.09亿元。终值占EV 66.9%，隐含退出倍数14.6倍，结果对WACC和远期状态敏感，因此184.09亿元只能作为这组条件下的基准结果。

**不合格表达**：

> 程序精确算出公司价值184.09亿元，因此公司就值这么多。把WACC改成8%后价值更高，证明股票被低估。

第二段把公式结果写成事实，又通过挑选参数制造想要的结论。

## 单变量实验：先预测方向

每题只改一个条件，其余保持基准：

1. WACC从9%升到10%，股权价值上升还是下降？
2. 显性期从7年改为5年，终值占比上升还是下降？
3. 永续增长从2%提高到2.5%，价值怎样变化？这能否证明2.5%更正确？
4. 只把终值写法从“2%永续增长”改成“10倍退出倍数”，其余不变，股权价值怎样变化？

<details>
<summary>完成后展开答案</summary>

1. 下降。脚本结果从184.09亿元降至157.22亿元，约下降14.6%。
2. 终值占比上升，从66.9%升至74.1%；更多价值被压进终值。注意股权价值同时从184.09亿元降到167.79亿元——显性期变短，少算了两年现金流。
3. 在其他条件不变且WACC仍高于永续增长时，价值会上升；但敏感性只给机械方向，不提供2.5%的经济证据。
4. 降至141.23亿元，降幅23.3%。这不是“换了个算法”，而是把隐含永续增长从2%换成了-0.91%。终值写法的切换永远同时切换了一个经济假设。

</details>

### 组合压力测试

单个“略保守”假设可能合理，但低增长、高WACC、低远期利润率和年末折现一起使用，会形成同方向偏向。反向压力测试应把整组假设翻转，再看核心方向是否仍成立，并披露结论余量。

Bear/Base/Bull也不能只把最后净利润乘0.8、1.0、1.2。合格情景要回到销量、价格、成本、Capex、营运资金和现金转化机制。

## 负对照：高终值占比不等于模型失效

只会盯着“终值占比超过70%就报警”的检查器，会把一整类长寿命资产判成不可用。读下面这段材料：

> 该收费公路剩余特许经营期26年，模型显性期取5年，第5年后按2%永续增长计算终值，终值现值占EV 74.1%。折现率9%，与同类特许经营资产的融资成本区间一致，取值依据见附表C-3。当期Capex 12亿元用于三处路面大修，已在FCFF中逐项扣除，未来五年的维持性Capex按里程和大修周期逐年列出。永续增长2%对应的隐含退出倍数已同时披露，并说明特许经营期结束后的资产处置假设为零残值。

这段材料里有三处**看起来危险但不应自动降级**：

| 表面信号 | 为什么当前不降级 |
|---|---|
| 终值占比高达74.1% | 资产寿命长、现金流稳定，高占比是业务性质的结果；而且远期假设已经写明并可质证 |
| 显性期只有5年，比常见的7—10年短 | 显性期长短本身不决定质量；关键是压进终值的那部分有没有被解释，这里解释了 |
| 当期Capex高达12亿元，压低了当期FCFF | 有逐项用途并已正确扣除；高投入不等于公式错误，反而说明现金流桥是完整的 |

真实缺口可能仍然存在——比如零残值假设是否与特许协议一致。但那要作为一条具体证据缺口提出，而不是因为“终值占比 > 70%”这条机械阈值降级。

**知道何时不该报警，和知道何时必须报警，是同一项能力的两半。**

## 进阶检查：把终值问题写成失败状态

到这里为止，基础学习者已经能亲手完成一套最小DCF并读懂敏感性。下面把同样的纪律写成 Agent 可执行的状态。

### 失败状态矩阵

第二列统一使用第1课的**记录验证状态**（已复核 / 部分可用 / 无法确认 / 明确错误）加**材料使用等级**。`cases/00-basics` 和 [`分层审计清单`](../docs/AUDIT-CHECKLIST.md) 里的“通过 / 警告 / 失败”是**清单项状态**，粒度不同，两套词不要混着写。

| 触发条件 | 记录验证状态 + 使用等级 | 影响 | 还不能断言 |
|---|---|---|---|
| 把当期周期峰值利润率直接作为终值利润率永久延续，且未讨论供给、价格与竞争 | 无法确认；终值与EV带条件使用或停止使用 | 终值可能被系统性抬高，EV和股权价值需重算 | 峰值一定不可持续，或公司被高估 |
| WACC 小于或等于永续增长率，模型仍打印终值 | 明确错误；停止使用终值及其下游 | 分母为零或负数，该终值公式没有可解释结果 | 换个公式后价值一定更低 |
| 模型不披露终值现值占EV的比重 | 无法确认（披露缺口）；EV带条件使用 | 无法判断结论依赖近端还是远端假设 | 底层折现计算一定算错 |
| 只报退出倍数，不报隐含永续增长 | 无法确认；终值带条件使用 | 最关键的远期假设被藏在倍数后面，本课示例中10倍隐含-0.91% | 该倍数一定不合理 |
| Bear/Base/Bull 只把结果乘0.8/1.0/1.2，没有经营机制 | 无法确认（情景无机制）；情景区间停止使用 | 区间宽度不携带任何经营信息 | 真实区间一定比它更宽或更窄 |
| 整组假设同方向偏保守，且未做反向压力测试 | 部分可用；结论带条件使用并披露余量 | 结果方向可能由假设组合而非经营事实决定 | 作者一定有意压低价值 |
| 显性期被拉长，但新增年份沿用同一条无证据的增长线 | 无法确认；EV带条件使用 | 远期假设只是从终值搬进明细期，质量未提高 | 长显性期一定比短显性期差 |
| 输出精度远超输入精度（输入约10亿元，输出声称精确到0.01亿元） | 部分可用；表述需修正 | 伪精确会让读者高估确定性 | 底层计算错误 |
| 终值占比高，但业务寿命、远期假设和敏感性都已披露 | 状态不变，不降级 | 按已披露区间继续使用并重点跟踪远期假设 | 高终值占比一定意味着高估 |
| 当期Capex很高且已在FCFF中逐项扣除 | 状态不变，不降级 | 当期FCFF较低被如实反映 | 高Capex一定创造或毁灭价值 |

## 运行环节：让判断可以被复算（必做）

先手工写出67.48、136.61、204.09和184.09四个结果，并预测哪个控制杆在本例权力最大，再运行：

```bash
python3 lab/mini_dcf.py
```

运行后逐段解释：

1. “五个数”分别控制什么；
2. 显性期与终值怎样加成EV；
3. 净债务怎样把EV变成股权价值；
4. 弹性排序为何只属于本案例；
5. WACC和年数变化后，哪些结果必须重算。

特别看两处：脚本的弹性排序把起点现金流显示为1.11而不是1.00，多出来的部分是净债务的杠杆放大；年数敏感性里5/7/10/15年对应的终值占比是74.1%/66.9%/58.3%/47.6%，本课负对照那段收费公路材料用的就是其中的74.1%。

脚本验证公式和方向，不验证10亿元FCFF、8%增长或9%WACC是否有现实依据。

## 闯关

1. WACC等于永续增长率时，应如何处理？
   - A. 继续计算，得到一个很大的终值
   - B. 该永续公式发散，必须调整模型约定并说明理由

2. 终值占比75%的收费公路模型一定失败吗？
   - A. 一定
   - B. 不一定，但必须重点检查剩余经营期、远期现金和折现率

3. Bear/Base/Bull只把净利润乘0.8/1.0/1.2，没有经营机制。最合适的记录验证状态是：
   - A. 无法确认；情景区间不携带经营信息
   - B. 已复核；三个情景都算对了

4. 输入增长提高1%，股权价值提高超过1%。最可能还受到什么影响？
   - A. 净债务使经营价值变化落到股权时被放大
   - B. 说明增长预测一定正确

5. 五个“略保守”假设全部压低价值，但未展示反向组合。你应：
   - A. 因为保守所以直接相信
   - B. 把整组假设反向压力测试，观察结论余量

6. 一份材料只给出“第7年按10倍FCFF退出”，不提永续增长。最合适的动作是：
   - A. 通过，退出倍数是市场做法
   - B. 反解隐含永续增长并要求质证，本例约为-0.91%
   - C. 直接判定该模型高估，因为倍数太低

7. 报告数字全部正确，只是没有写终值占EV的比重。受影响的是什么？
   - A. 计算结果本身，必须重算
   - B. 可质证性，属于披露缺口；数值不变但结论要带条件

<details>
<summary>完成后展开答案</summary>

1. **B**。分母为零或负数时，这套终值公式没有可解释结果。
2. **B**。高终值占比是质证信号，不是统一失败线。本课负对照那段材料终值占比74.1%，仍然不降级。
3. **A**。结果缩放不是经营情景，无法验证量、价、成本和现金联动。注意用记录验证状态词，不要写成清单项的“警告”。
4. **A**。净债务使股权价值基数小于EV，同一经营变化在股权端的百分比更大。
5. **B**。保守不等于中立，组合方向必须量化。
6. **B**。倍数同时锁定了一个远期增长假设；要求的是把它写出来，不是换一个数。C 越过了证据，-0.91%是否合理取决于这门生意会不会长期萎缩。
7. **B**。数值一个都没错，降级的是可质证性。把披露缺口说成计算错误，是另一种不准确。

## 本课边界

你已经亲手完成一套最小DCF，能够解释显性期、终值、EV、股权价值和敏感性，并知道退出倍数与永续增长互为镜像。你还没有证明任何现实公司的增长、WACC或终值假设正确。

第1课列出的六个失败模式，本课交付了两个：**峰值永久化**（远期状态那一格）和**隐藏终值**（不披露占比、只报倍数不报隐含增长）。两者各自落到失败状态矩阵的一行和练习表的一行，而不是停在“要小心终值”。

下一课不再问“按我的假设值多少”，而是用 [`反向DCF`](DAY-5.md) 问“当前价格要求什么”。
