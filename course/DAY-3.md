## 10分钟白话解释

一个输入不能只有名字和数字。最低限度要回答：

| 身份 | 要问的问题 | 常见失败 |
|---|---|---|
| 对象 | 是发行人整体、某类证券还是业务分部？ | A股价格乘了A+H全部股份，却命名为A股流通市值 |
| 指标与范围 | 是合并收入、归母利润、现金还是有息债务？ | 用合并经营价值，却漏掉少数股东权益 |
| 期间与时点 | 数字属于哪个报告期，在哪个估值日有效？ | 8月价格接去年末资本结构，中间融资无人处理 |
| 数值、单位与币种 | 元、万元还是亿元；人民币还是港币？ | 100万元被当成100亿元，放大一万倍 |
| 信息性质 | 是事实、指引、预测还是内部假设？ | 单家券商预测被写成市场共识 |
| 来源与证据 | 谁发布、何时发布、能否回到具体记录？ | 只留网站首页，历史值已无法复取 |

第1课讲的是“怎样记录”；今天把它用于估值：只要输入进入FCFF、EV桥、折现或每股分母，它的身份就会决定最终数字的经济含义。

### 对象先于数字

假设一家公司同时有A股和H股。你可以计算发行人全部普通股的股权价值，也可以观察某类证券的市场价格，但不能静默混用：

- 发行人股权价值对应全部相关普通股股东；
- A股收盘价只是一类证券的报价；
- “A股流通市值”应使用A股流通数量；
- 用A股价格推算全公司价格等价可以是一项诊断，但必须这样命名，并先核对A/H每股经济权利和换算关系。

多个股本数字同时出现不自动等于错误。总股本、外部普通股、流通股和库存股可以各自正确；真正的问题是定义隐藏或用途混用。

### 日期不同不等于日期错误

真实估值几乎总会遇到异步数据：市场价格是今天的，最近财报可能是三个月前的。正确问题不是“日期是否完全一样”，而是“中间发生了什么，怎样桥接到估值日”。

```text
最近财报日资本结构
+ 期间新增融资
- 期间偿债
+ 期间经营现金流
- 分红、回购、收购等现金流
= 估值日资本结构估计
```

桥不一定要精确到个位数。若期间变化不重大，可以说明证据和影响区间；若已知发生50亿元发债和30亿元现金收购，却仍原样使用旧数字，当前股权价值桥就是已确认失败。

### 单位和币种必须随数字同行

`100`本身没有经济意义。它可能是100元、100万元、100亿元、100百万港元，也可能是100%。专业材料至少保存原值、单位、币种、换算日和换算规则。

数量级错误会穿过整条模型：FCFF若放大一万倍，EV通常也会接近同比例放大。换汇错误的方向不能靠“乘还是除”的记忆判断，必须写明：

```text
1港元 = 0.865人民币
100亿港元 × 0.865 = 86.5亿元人民币
```

### 来源能打开，不代表历史值能复取

只保存一个“今日汇率”网址，明天打开会得到新数字，不能证明模型昨天使用了什么。关键市场输入至少要有截点、原始记录或冻结文件，以及能定位到具体表格或数据行的证据指针。

同时执行PIT检查：来源发布日期必须不晚于研究时点。后来公布的数据可以用于事后复盘，不能伪装成当时已知输入。

## 完整示例：把五个输入对齐

研究者要在8月17日计算长河制造的每股价值，拿到以下材料：

| 输入 | 原始状态 | 需要补的桥 |
|---|---|---|
| A股收盘价 | 8月17日，人民币/股 | 明确只代表A股证券报价 |
| 汇率 | 8月17日，`1港元=0.865人民币` | 保存当日记录和报价方向 |
| 现金、债务 | 6月30日，亿元人民币 | 检查7月1日至8月17日融资、偿债和重大现金流 |
| 股本 | 7月月报，含600万库存股 | 计算外部普通股并说明A/H范围 |
| 2027年收入 | 单家券商7月22日预测 | 标为外部预测，不命名为共识 |

如果期间没有重大融资，研究者又把期间现金流按0—10亿元做了区间，日期虽不同，材料仍可带着条件继续使用。若完全不检查期间变化，就不能因为公式能运行而把资本结构视为已复核。

## 好坏对照

**输入可继续用**：

> 估值对象为长河制造全部外部普通股；估值日为8月17日。价格和汇率取当日收盘，现金债务取6月30日。经公告检查，期间无发行股份或新增债券；7月1日至8月17日经营现金流按0—10亿元区间桥接。金额统一为亿元人民币。2027年收入125亿元来自一份7月22日券商报告，标为单家外部预测。

**输入停止使用**：

> 长河制造合理价值为每股25元。价格取8月17日，现金债务取去年末，股本来自旧模板；收入125亿元为市场一致预期，来源见某财经网站。

后一段无法确认对象、股本、期间变化、共识样本和历史证据。如果进一步确认期间完成大额融资或单位错配，相关计算从“无法确认”升级为“失败”。

## 单变量实验：什么会变，什么不该变

以“股权价值170亿元、10亿外部普通股、每股17元”为基准：

1. 只把股数改为12.5亿股，每股价值是多少？
2. 只把170亿元的单位标签改成170万元，数值不变，应怎样处理？
3. 只把来源页码从42页改为43页，且数值确实能在43页定位，状态是否变化？

<details>
<summary>完成后展开答案</summary>

1. `170 ÷ 12.5 = 13.6元`。股权价值及其上游公式不变，每股派生值必须更新。
2. 明确错误。单位与数值自相矛盾，全部依赖该金额的派生值失效；信息性质、发布时间和来源身份不因此改变。
3. 状态不变，不降级。证据仍可定位；机械地看到页码变化就报警属于误报。

</details>

## 五分钟一句话输出

任选一份估值摘要，按以下格式写五行：

```text
对象与证券：
估值日与异步数据桥：
单位、币种与股本：
最重要的来源缺口：
当前等级与还不能断言：
```

不要写“数据看起来没问题”。写出具体日期、单位、来源和它影响哪一步计算。

## 闯关

1. 价格和资本结构相差四个月，但期间没有重大融资，模型量化了期间现金流。应如何判断？
   - A. 日期不同所以必然失败
   - B. 可以继续使用，但要检查桥接依据与区间

2. 输入只写“Beta 0.9，行业惯例”，没有数据、窗口和市场基准。最合适状态是：
   - A. 通过
   - B. 警告或无法确认

3. A股价格乘A+H全部股份，被命名为“A股流通市值”。这是：
   - A. 对象/语义失败
   - B. 只是格式问题

4. 财报单位为百万元，模型按亿元读取，数值不变。最直接影响是：
   - A. 只影响展示
   - B. 进入模型的金额放大100倍，依赖它的结果必须重算

5. 汇率网址今天仍能打开，但只返回今天值。它能否证明三个月前模型使用的汇率？
   - A. 能
   - B. 不能，需要历史记录或冻结证据

<details>
<summary>完成后展开答案</summary>

1. **B**。异步已被识别和处理，下一步验证桥接，而不是按日期不同自动否决。
2. **B**。Beta无法复算，也不知道是否与证券、市场和窗口匹配。
3. **A**。该计算可以另有用途，但不能冒充A股流通市值。
4. **B**。百万元到亿元相差100倍；不是小数点格式问题。
5. **B**。网址可访问不等于历史输入可追溯。

</details>
