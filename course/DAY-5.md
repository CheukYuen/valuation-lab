## 先闭卷回忆

不看第4课，写下最小DCF的六个输入：起点现金流、增长、显性期、永续增长、折现率和________。

再回答：如果当前市场股权价值高于模型基准价值，要在其他条件不变时解释它，通常需要更强还是更弱的经营假设？

## 10分钟白话解释

正向DCF从假设走向价值：

```text
经营预测 → FCFF → 折现 → EV → 股权价值
```

反向DCF把问题倒过来：

```text
当前股权价值 → 对应EV → 所需FCFF → 所需增长、利润率或持续时间
```

它不预测未来，也不读取市场参与者脑中的统一答案。它只是说：**在指定模型约定下，要让公式等于当前价格，某个经营变量必须达到什么水平。**

因此反向结果必须是一条条件句：

> 在WACC 9%、显性期7年、永续增长2%、净债务20亿元和本课FCFF定义下，300亿元股权价值要求显性期FCFF年增长约16.25%。

删掉任一条件，“16.25%”就像失去单位的数字，无法解释。

### 先对齐股权价值和EV

本课命令接收的是**当前股权价值**300亿元。模型内部仍要经过资本结构桥：

```text
目标EV = 目标股权价值 + 净债务
       = 300 + 20
       = 320亿元
```

如果输入本来就是EV，却再次加净债务，反解会要求不必要的高增长。反向DCF首先要继承正向模型的对象、单位、币种、FCFF和EV桥。

## 完整示例：300亿元要求什么

第4课基准模型的股权价值是184.09亿元，当前教学股权价值设为300亿元：

```text
差距 = 300 ÷ 184.09 - 1 = 63.0%
```

“市场比模型高63%”不等于市场错误，也不等于公司必须增长63%。价值由多年的现金流和终值共同决定，需要让求解器在保持其他输入不变时寻找增长率。

### 固定其他条件，只反解增长

| WACC | 所需显性期年增长 |
|---:|---:|
| 7% | 9.68% |
| 8% | 13.14% |
| 9% | 16.25% |
| 10% | 19.11% |
| 11% | 21.78% |

同一个300亿元，在WACC 7%时要求增长9.68%，在11%时要求21.78%。变化的不是公司现实增长，而是模型对未来现金要求的折现约定。

### 固定增长，只反解起点FCFF

| WACC | 所需起点FCFF | 相对10亿元基准 |
|---:|---:|---:|
| 7% | 11.02亿元 | +10.2% |
| 8% | 13.33亿元 | +33.3% |
| 9% | 15.68亿元 | +56.8% |
| 10% | 18.06亿元 | +80.6% |
| 11% | 20.46亿元 | +104.6% |

16.25%增长和15.68亿元起点FCFF是两条不同解释路径。它们都不是市场共识，只是在分别固定其他变量后得到的条件解。

## 为什么不存在唯一隐含观点

下面的调整都可能提高模型价值：

- 起点FCFF更高；
- 收入增长更快；
- 利润率更高；
- 现金转化更好；
- 高增长维持更久；
- WACC更低；
- 远期状态更强。

真实价格可能由这些变量的无数组合解释。专业反向DCF至少展示一条曲线或多组组合，并明确一次只反解了哪个变量。

### 从数学答案回到经营问题

得到16.25%以后，研究才刚开始：

| 质证方向 | 要问什么 |
|---|---|
| 历史 | 公司过去是否在相同基数和周期位置实现过？ |
| 同行 | 可比业务是否做到过，口径和周期是否一致？ |
| 产能 | 销量增长是否需要新产能，何时投产？ |
| 价格与份额 | 增长来自涨价、行业扩张还是抢份额？ |
| 再投资 | Capex和营运资金是否支持增长，FCFF定义是否仍成立？ |
| 持续时间 | 16.25%需要维持七年，还是只维持两年？ |

反向DCF把“贵不贵”的争论改写成可取证问题，但不替你回答这些问题。

## 三种“无解”不要混在一起

| 类型 | 含义 | 正确动作 |
|---|---|---|
| 公式无效 | 如WACC不高于永续增长 | 修正模型约定，不打印伪结果 |
| 搜索范围无解 | 求解器只搜索到100%增长，目标仍在范围之外 | 检查范围、单位、对象和EV桥；如扩大范围必须披露 |
| 经济不可行 | 数学能解，但要求长期利润率超过100%或产能远超物理上限 | 标记该组约定下缺乏经济可行解释 |

不能为了得到一个可打印数字就不断放宽边界。无解本身是诊断信息；同时也要先排除把万元当亿元、把EV当股权价值等基础错误。

## 好坏对照

**合格输出**：

> 在本课FCFF定义、净债务20亿元、7年显性期、2%永续增长下，300亿元股权价值在WACC 7%—11%时要求FCFF年增长约9.68%—21.78%。基准WACC 9%对应16.25%。下一步需与公司历史、产能、再投资和现金转化比较；该区间不是市场共识，也不证明公司能够实现。

**不合格输出**：

> 市场隐含公司未来增长16.25%，因此低于这个预测就是悲观，高于就是乐观。

后一段隐藏了折现率与全部替代组合，还把模型条件伪装成市场统一观点。

## 单变量实验：先预测，再求解

2. WACC仍为9%，只把目标股权价值降低，隐含增长通常怎样变化？
3. 数学解出长期EBIT利润率110%，是否应把110%当普通预测写入Base？

<details>
<summary>完成后展开答案</summary>

1. 从16.25%升至19.11%。折现要求更高，需要更强现金流才能解释同一价格。
2. 通常下降；需要解释的价值更低。实际方向仍应由同一公式复算。
3. 不应。应标为该组约定下的经济不可行区，并检查对象、口径和模型选择。

## 口径一致检查

正向模型若逐年使用：

```text
FCFF = EBIT × (1 - 税率) + D&A - Capex - 营运资金增加
```

反向模型却改用“收入 × 利润率 × 80%固定转化率”，正向情景增长与反向隐含增长就不在同一根轴上。0.80不一定错，问题是口径切换没有解释和敏感性。

检查反向DCF时至少对齐：估值对象、股权价值与EV、现金流定义、税率、显性期、终值、折现时点和WACC。

## 闯关

1. 反向DCF得到增长20%，能否称为市场共识？
   - A. 能
   - B. 不能

2. 折现率从8%变为10%，隐含增长从13%升至19%。这说明：
   - A. 公司实际增长改变了
   - B. 隐含要求高度依赖模型约定

3. 输入300亿元本来是EV，模型却按股权价值再加20亿元净债务。最可能结果是：
   - A. 反解要求被抬高
   - B. 没有影响

4. 反解无经济可行解释时，正确做法是：
   - A. 记录无解区域，并检查对象、口径和模型约定
   - B. 不断放宽假设直到得到可打印数字

5. 正向与反向模型使用不同FCFF定义，但结果数字接近。可以自动通过吗？
   - A. 可以，结果接近即可
   - B. 不可以，先统一或桥接口径再比较

<details>
<summary>完成后展开答案</summary>

1. **B**。它是模型条件下的要求，不是调查得到的共识。
2. **B**。现实没有改变，改变的是折现约定。
3. **A**。目标EV被错误增加20亿元，求解器会要求更多现金流。
4. **A**。无解是诊断结果，不应被静默抹掉。
5. **B**。数值偶然接近不能修复定义错位。

</details>

## 本课边界

你现在能把价格翻译成一组可质证的经营要求，并识别多解、口径错位和经济不可行区。反向DCF不证明公司能或不能实现要求，也不直接回答证券是否值得买。
