# 第7天：长飞综合练习

**本课目标**：在真实复杂材料中解释估值链条、复算关键结果，再分别评价工程质量、经济假设和方法适用性。预计60分钟。

## 先闭卷回忆

合上前六课，写出：

1. `EBIT → FCFF → EV → 股权价值 → 每股价值`中每个箭头至少检查什么？
2. DCF五个控制杆是什么？
3. 反向DCF结果必须披露哪些条件？
4. 方法计算正确与方法适合，有什么区别？

今天不是找一串错误，而是交出两样完整成果：一份估值解释，以及一份有证据的检查结论。

## 10分钟白话解释

真实模型很少“全好”或“全坏”。一份材料可以同时做到：资本结构逐元可复算、程序测试通过、方法方向合理，但经营情景缺乏证据。也可能叙述很专业，却把两套现金流定义放在同一张图上比较。

因此要把四种判断分开：

| 判断层 | 核心问题 | 典型证据 |
|---|---|---|
| 估值解释 | 这套模型怎样从经营走到价值？ | 输入、公式链、情景、EV桥、每股口径 |
| 模型工程质量 | 数字、单位、公式和程序能否复算？ | 冻结输入、计算程序、测试、来源指针 |
| 经济假设质量 | 销量、价格、利润率、现金转化和持续时间有何依据？ | 财报、公司指引、外部预测、经营驱动桥 |
| 方法适用性 | 正向/反向DCF及其他校验是否适合周期与业务结构？ | 方法选择理由、口径一致、替代组合 |
| 投资吸引力 | 当前价格是否值得承担风险？ | 还需要组合、催化剂、风险偏好等研究；本课不回答 |

前四项中的前三类检查做得好，也不能自动推出第五项。课程中的长飞数字用于冻结案例教学，不是当前目标价或交易建议。

### 先解释，再检查

如果你无法用自己的话说清模型怎样得到价值，就很难判断问题影响了哪一步。正确顺序是：

```text
对象与估值日
→ 输入和信息性质
→ FCFF定义
→ 显性期与终值
→ EV到股权价值
→ 情景或反向要求
→ 敏感性
→ 可靠性与使用等级
```

不要一开始打开JSON找数字，也不要先读答案收集“标准错误”。渐进披露是为了测试你自己的判断能否从正文一路追到计算和证据。

## 本案例为什么适合毕业练习

长飞案例同时含有：

- 发行人整体与A/H两类证券；
- 市场估值日与资本结构报告日不同；
- 周期利润与结构成长叠加；
- Bear外部预测和Base/Bull内部情景；
- 正向DCF、反向DCF、终值与现金转化；
- 可运行程序以及并不完整的原始存证。

这些因素会互相影响，所以严重性不能按“发现了几条”决定。要看问题是否改变核心价值、最可引用表述或本次材料用途。


如果正文无法支持某一行，写“无法确认”，不要提前去代码替报告补答案。

### Level B：检查关键假设

再读来源方案及报告相关章节，沿五条线检查：

1. 正向FCFF和反向FCFF是否同定义；
2. Bear/Base/Bull能否回到销量、ASP、成本、产能、利润率和现金转化；
3. 预测起点是否与已知实际数据对质；
4. 资本结构日到估值日的现金流是否进入模型；
5. 终值、WACC和反向要求是否展示合理区间及经济无解区。

Level B的输出不是“问题很多”，而是每条写出证据、影响的计算或表述，以及仍不能断言什么。

### Level C：复算与存证

必做的是本课后面的 `knobs.py` 旋钮实验。它会读取冻结输入并在内存中重算，不要求你读代码。

## 怎样复算而不被数字牵着走

运行前先对每个实验写方向预测：

| 实验 | 先写什么 | 运行后回答什么 |
|---|---|---|
| 三情景基准 | Bear/Base/Bull的排序和终值占比排序 | 数字是否复现，区间由什么拉开 |
| 单变量旋钮 | WACC、永续增长、利润率和收入分别怎样影响价值 | 谁在当前案例中控制结果，不能推广什么 |
| 假设叠加 | 整叠保守选择反转后方向会不会翻转 | 结论余量还剩多少，哪些风险没覆盖 |
| 正反向口径 | 现金转化提高时隐含要求如何变化 | 两套定义能否直接比较 |

敏感性实验验证“如果改变输入，程序会怎样算”；它不证明新输入更正确，也不覆盖没有进入实验的未知因素。

## 严重性与使用等级

使用 [`分层审计清单`](../docs/AUDIT-CHECKLIST.md) 的四档严重性：

| 严重性 | 含义 | 典型处理 |
|---|---|---|
| 致命 | 已确认足以使核心输出失效 | 停止使用，修正重算 |
| 重大 | 很可能改变方向、区间或最可引用结论 | 带条件使用，量化敏感性 |
| 次要 | 影响披露或局部回查，不太可能单独翻转方向 | 记录并修复 |
| 暂无法确认 | 证据不足，影响大小也未知 | 保持未知，不替材料补答案 |

同一种问题在不同材料里严重性可以不同。三个月日期差在稳定、无重大事项的公司可能次要；若期间刚完成大额融资，就可能使EV桥失效。

整份材料的三档使用等级也不是数问题数量：

- **可继续使用**：核心链条可复算，关键假设有依据，剩余缺口不影响当前用途；
- **带条件使用**：部分方向可参考，但重大缺口仍可能改变区间或表述；
- **停止使用**：对象、单位、核心公式或方法已确认失效，修复前不能引用核心结果。

## 好坏对照

**合格综合结论**：

> 报告以反向DCF诊断周期和结构成长的市场要求，并保留多情景正向价值，方法角色基本合理。资本结构与核心公式可复算；但某项现金流口径和Base/Bull经营驱动仍需核对，因此当前只能带条件使用。这个等级评价材料可靠性，不回答A股或H股是否值得买。

**不合格综合结论**：

> 程序通过测试，所以假设可信。模型有十个问题，所以长飞一定高估。

前一句把工程正确当成现实证据；后一句按数量定严重性并越过投资边界。

## 单变量练习：给问题定影响范围

假设你发现以下三项，每次只看一项：

1. 市场价格的小数位显示错误，但底层计算使用的原值正确。
2. 正向与反向DCF现金流定义不同，而报告把两个增长率直接比较。
3. 一个辅助倍数缺少可比公司样本，但主DCF输入和公式完整。

<details>
<summary>完成后展开答案</summary>

1. 通常是次要展示问题；修复显示即可，不能让底层价值连带失效。
2. 影响最可引用的跨口径比较，通常至少是重大问题；先统一定义或给出桥接和敏感性。
3. 辅助校验无法确认，不自动推翻主DCF；是否影响总等级取决于主结论是否依赖该倍数。

</details>

练习的重点是保护影响边界：既不放过核心错配，也不把局部缺口升级成全局失败。


运行后只允许做三类修改：

不要因为看到脚本输出，就把输入依据从“无法确认”升级为“通过”。程序复算和经济验证是两件事。

## 五分钟一句话输出

压缩整页内容为一句：


## 闯关

1. 计算程序全部通过测试，是否足以证明经营假设可信？
   - A. 足够
   - B. 不足够

2. 方法适合但关键销量和ASP无证据，最可能的等级是：
   - A. 带条件使用
   - B. 因方法正确而自动通过

3. A/H股本和公式正确，能否仅凭此判断A股值得买？
   - A. 能
   - B. 不能

4. 一个重大问题影响报告最可引用结论，五个次要问题只影响展示。严重性排序应怎样？
   - A. 五个次要问题更重要，因为数量多
   - B. 重大问题优先，因为影响核心用途

5. 旋钮实验中某个乐观组合仍未翻转方向，可以断言所有未知都不会翻转吗？
   - A. 可以
   - B. 不可以，只能描述已测试组合

<details>
<summary>完成后展开答案</summary>

1. **B**。工程正确只证明输入被一致计算，不证明输入有经济依据。
2. **A**。方法和经济证据要分别评价。
3. **B**。对象正确是估值前提，不是投资结论。
4. **B**。严重性由对结论和用途的影响决定，不由数量决定。
5. **B**。敏感性只能覆盖实际改变过的参数与组合。

</details>

## 对答案后的自评

完成自己的结论后才看 [`答案`](../cases/01-yofc/answer-key.md)。不要只数漏项，把每个差异归类：

- **不知道该查**：回到相应课程，把触发信号写入自己的快速门；
- **知道但查不动**：补术语、报表或数据来源能力；
- **查到了但严重性不同**：比较它对核心输出的真实影响；
- **答案可能过重或遗漏**：保留你的证据与反证，不默认答案完备。

## 本课边界

毕业代表你能解释、复算并检查一套简化估值，能够给出有证据的使用等级。它不代表你已经能独立预测真实公司的全部未来，也不代表你能据此作出交易决策。
