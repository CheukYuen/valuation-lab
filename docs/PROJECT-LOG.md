# 项目方向与当前进展

本文件只记录 Git 提交无法清楚表达的关键方向、阶段切换和重大范围决定。普通文件改动、测试结果和提交历史以 Git 为准，不在这里重复记录。

## 关键历史

1. **第一阶段：七天估值课程**

   项目最初采用七天课程形式，重点是学习简化估值并检查估值对象、输入、方法、假设和结果是否可靠。

2. **当前阶段：真实公司估值实战**

   七天课程已经学完。项目转向真实公司估值实战：先理解财务指标和估值方法的 `What → Why → How`，再完成真实案例。长飞光纤是第一个案例，中天科技是第二个案例，后续可扩展到美股及其他公司。

## 当前进展

- 长飞光纤案例已形成财务、预测、估值、券商方法和产业信息文档。
- 长飞 DCF 的折现率已从“三个直接给定的 WACC”改为按 CAPM 推导的统一 10.49%（Beta 由 258 周回归得到，无风险利率和股权风险溢价仍借用券商可见输入）。三情景每股价值相应变为 13.47、30.47、49.11 元；差异不再包含折现率对经营判断的二次计价。
- 中天科技案例已补2025年报、2026年半年报和datahub快照，完成从光纤产品变化到集团FCFF的三情景估值：下行28.50元、基准41.75元、上行51.84元。
- 已增加以光纤为例的“行业-产业链-公司-估值-验证”个人最小有效投研流程。
- 根目录 `CLAUDE.md` 继续只保留文档入口和常用命令。

## 下一步

- 补齐长飞 WACC 仍缺的两项原始来源：定价日中国 10 年期国债收益率和股权风险溢价。
- 用后续分部披露替换中天科技当前集团层现金流假设，并逐期对照2026E-2028E预测。
- 将长飞和中天案例沉淀为可复用的个人投研模板，但不混合两家公司的业务假设。
