# 快速科学学习法

快，不是把材料读得更快，而是用更少时间形成可迁移的判断力。

互动版本见 [`web/study-methods.html`](../web/study-methods.html)。

## 每课45分钟

1. **5分钟闭卷回忆**：不看上一课，写3个重点和1个未知。
2. **12分钟学习新概念**：术语先用自己的话复述。
3. **15分钟先答后看反馈**：主动回忆，不用重复阅读制造熟悉感。
4. **8分钟只改一个条件**：先预测方向，再用工具验证。
5. **5分钟一句话输出**：写清“为什么可疑、影响什么、还不能断言什么”。

## 六个有效方法

- **主动回忆**：关闭材料后作答；看懂不等于能从记忆中提取。
- **间隔复习**：当天、次日、第3天、第7天各用5–10分钟重现一次。
- **交错练习**：混合股本、时点、现金流和方法题，训练识别而非背题型。
- **范例渐隐**：完整示范 → 遮住答案 → 只给原始材料；长飞Level A/B/C按此设计。
- **错误日志**：只记漏项、原因和下次触发信号，不抄整份答案。
- **信心校准**：作答前写60%/80%信心；高信心错题优先修正。

## 错误日志模板

```text
我漏掉：
原因：不知道该查 / 知道但查不动 / 严重性判断错
下次看到什么信号会想起来：
作答前信心：__%
修正后的一句话规则：
```

## 停止无效学习

出现以下任一情况就停止阅读，改做一道题：

- 连续阅读20分钟，没有闭卷输出；
- 把答案抄进笔记，却没有自己解释；
- 连续只练同一题型；
- 看懂代码，就认为自己已经会判断模型。
