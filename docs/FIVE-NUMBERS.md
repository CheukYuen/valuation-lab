# 五个数、终值、反解

这是本仓库的全部理论。读完就够开始审了，不必先读教科书。

---

## 一、DCF 只有五个数

不管模型有多少个 sheet，它最后都在算这五件事：

| # | 是什么 | 在模型里通常叫 |
|---|---|---|
| 1 | 起点能收多少现金 | `FCF` / `FCFF` / `NOPAT` |
| 2 | 增长多快 | 收入增速、利润率路径 |
| 3 | 这样能持续多久 | 显性期年数、峰值持续期 |
| 4 | 之后值多少 | 终值 / `TV` / `Terminal Value` |
| 5 | 按什么利率折回今天 | 折现率 / `WACC` / `贴现率` |

看不懂一个模型的时候，第一件事是把这五个数找出来。找不到第 3 和第 4 的模型，通常是把它们藏在了一个倍数里。

跑一次感受一下：

```bash
python3 lab/mini_dcf.py
```

整个模型 40 行，全部在 `lab/mini_dcf.py` 的 `value()` 里。看得懂这 40 行，就看得懂任何 DCF 的骨架。

## 二、权力不在你以为的地方

`mini_dcf.py` 输出的**弹性排序**是这个仓库最值钱的一张表。弹性 = 价值变动百分比 ÷ 输入变动百分比。

默认输入下的结果：

```
discount_rate        -1.48
base_fcf              1.11
growth                0.49
terminal_growth       0.23
```

折现率的权力是增长率的三倍。而在真实研报里，增长率被讨论十页，折现率写在附录一行。

在长飞的真实模型上更极端（`cases/01-yofc/knobs.py` 实验 1）：

- 把辛苦预测的**整整七年收入全部抬高 10%** → 价值 +10.9%
- 折现率从 6.6% 挪到 8.0% → 价值 **−24.3%**

**结论：争论最激烈的地方影响最小，没人争论的地方决定一切。** 建立这一个直觉，你看研报的方式就永久改变了。

## 三、终值占比是诚实度指标

终值现值 ÷ 企业价值。这个比例告诉你：结论有多少来自那张详细的预测表，有多少来自最后三个拍出来的参数。

长飞三情景的实测值：Bear 37.6%、Base 57.9%、**Bull 69.0%**。

Bull 的意思是：**69% 的价值来自 2032 年以后**——来自终值利润率、永续增长、终值 ROIC 这三个数，而不是那张七年明细表。

一般读法：

| 终值占比 | 意味着 |
|---|---|
| < 40% | 结论主要由可核查的显性期支撑，可信度较高 |
| 40–60% | 正常范围，但终值参数需要单独质证 |
| > 60% | 结论主要是信仰。显性期表格是装饰 |

显性期拉长会降低终值占比，但那不是变严谨了——只是把假设从终值挪进了表格。`mini_dcf.py` 底部的年数敏感性演示了这一点。

## 四、反解：从零起步最短的一条路

**不要问「值多少钱」，要问「现在的价格要求什么」。**

「长飞值 700 亿还是 1400 亿」——你答不了，我也答不了，那需要预测未来。

「当前 H 股价格要求 2028 年以后长期维持 26% 的 EBIT margin」——这是一个**你能查的事实问题**：这家公司历史上到过 26% 吗？行业里谁做到过？维持了几年？靠什么维持的？

反解把「预测未来」（你不会）换成了「核对历史」（你会）。这就是整个方法的窍门。

```bash
python3 lab/reverse.py 300
```

两条纪律：

1. **反解的输出不是一个数，是一条曲线。** 换个折现率，要求就变。默认输入下，同一个市值要求的年增长在 9.68%（折现率 7%）到 21.78%（折现率 11%）之间。谁给你一个反解结果而不给折现率，谁就是在把自己的假设伪装成市场的观点。
2. **「无解」本身就是结论。** 如果解出来需要 100% 的 EBIT margin，那不是「市场要求很高」，那是**当前价格无法由这组假设的经济含义解释**。不要换一组更宽松的假设去凑出一个能印出来的数字。

这套方法有个正式名字叫 Expectations Investing。长飞那份估值方案选它当主方法，对那个商业模式是恰当的。

## 五、什么方法配什么生意

「适不适合」看的是商业模式，不是公司名字：

| 商业模式 | 主方法 | 为什么 |
|---|---|---|
| 周期品（光纤、化工、航运、面板） | 周期正常化 + 反向 DCF | 峰值利润不能永久化，单一 `P/E` 必错 |
| 稳定现金流（公用事业、收费站） | DCF / 股息折现 | 现金流可预测，折现率是主战场 |
| 平台 / 订阅 | 单位经济 + 长期利润率 | 当期利润被获客支出掩盖 |
| 重资产成长 | `EV/EBITDA` + 资本回报 | 折旧口径差异大，净利润不可比 |
| 早期 / 无盈利 | **DCF 不适用** | 五个数里四个不可知，别硬套 |

长飞卡在两段之间：普通光纤是周期品，空芯光纤和光互联是结构成长。**这就是为什么给它套单一 `P/E` 一定错**——你在给一个正在变化的东西套一个静态倍数。

## 六、最小阅读

只两个，不要贪多：

1. **《Expectations Investing》**（Rappaport & Mauboussin）——就是上面第四节的方法，约 200 页，数学不超过四则运算。只读懂「反过来问」那一章就回本。
2. **Damodaran 的公开网站**（NYU Stern）——不要读他的教科书，读他每年更新的公开数据和博客。长飞模型里 5.14% 的中国股权风险溢价就出自那里。

其余先不要碰。**你不需要会建模。**
