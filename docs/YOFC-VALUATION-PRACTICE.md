# 长飞光纤估值学习与实战方案

## 目标

这是一个以长飞光纤光缆股份有限公司（下称“长飞光纤”）为真实案例的估值学习与实战项目。

学习者已经完成原有课程。新内容不再围绕“七天课程”展开，也不把检查、Agent、数据契约或网页实现当成主线。每个主题先回答估值方法和财务指标的 `What → Why → How`，再使用长飞光纤的真实公开数据完成计算、解释与方法对照。

完成后，学习者应当能够：

1. 用白话说明常用财务指标和估值方法是什么、为什么有用、如何计算。
2. 从正式披露中找到原始数据，理解口径，并亲手完成长飞光纤的真实案例。
3. 使用多种常见方法形成可复算的现实估值区间，而不是依赖单一公式或单点结果。
4. 解释不同方法为何得出不同结果，以及结果依赖哪些经营、增长和风险假设。
5. 区分事实、外部预测、内部假设、派生计算和分析判断。

## 内容组织方式

每个主题按以下顺序展开：

1. **What：是什么**——先用白话解释定义、经济含义和常见口径。
2. **Why：为什么看**——说明它回答什么问题、适合什么场景、不能说明什么。
3. **How：怎么算**——列出公式、原始数据、单位、期间、币种和计算步骤。
4. **长飞真实案例**——从长飞光纤正式披露出发，逐项代入并展示中间过程。
5. **结果解释**——解释数字背后的业务含义、适用边界和主要不确定性。
6. **方法对照**——必要时与其他指标、估值方法或可比公司交叉比较。

不要先堆检查清单，再补估值知识。检查只在实际计算中出现，用于解决真实的口径、时点、单位、来源或适用性问题。

## 真实案例范围

- 公司主体：长飞光纤合并报表口径。
- 上市证券：A 股 `601869.SH` 与 H 股 `06869.HK`。
- 财务事实基准：长飞光纤 **2026 年中期报告**，并结合必要的历史年度报告形成至少五年的观察序列。
- 估值时点：每次计算必须明确价格日期、财报可得日期、汇率日期和所用股本；不得使用在该估值时点尚未公开的信息。
- A/H 股处理：先估企业整体经营与价值，再明确总股本、A/H 股类别、币种、汇率和两地市场价格差异，避免把公司价值和某一市场的证券价格混为一谈。
- 可比公司：选择 3–5 家业务、盈利模式和资本结构具有实际可比性的公司，并逐家解释为何可比；不得只凭行业标签组成可比组。

如果 2026 年中期报告尚未正式披露或关键字段缺失，必须明确标记 `MISSING`，说明暂用的最近正式报告及其局限，不得把预测数冒充中报实际数。

## 财务指标主线

常用财务指标至少覆盖以下六组，并串联三大报表：

1. **规模与增长**：营业收入、收入增速、营业利润、归母净利润及其增速。
2. **盈利能力**：毛利率、营业利润率、净利率，以及影响利润率变化的主要业务因素。
3. **资本回报**：净资产收益率（Return on Equity，ROE）、投入资本回报率（Return on Invested Capital，ROIC）、投入资本、资本成本，并说明分子分母的口径匹配。
4. **营运效率**：应收账款、存货、应付账款、周转率/周转天数和营运资本变化。
5. **现金流与投入**：经营现金流、资本开支、折旧摊销、企业自由现金流（Free Cash Flow to Firm，FCFF）、股权自由现金流（Free Cash Flow to Equity，FCFE），以及利润和现金流的差异。
6. **资本结构与每股指标**：现金、有息债务、净债务、利息保障、总股本、每股收益（Earnings per Share，EPS）、每股净资产和股东回报。

每个指标都必须说明：

- 定义和经济含义；
- 为什么使用；
- 公式以及采用该口径的原因；
- 原始报表字段和来源；
- 长飞光纤的真实计算；
- 历史变化与可比公司对照；
- 常见误读、适用边界和当前未知项。

指标不是孤立的名词表。内容应帮助学习者理解：收入如何形成利润，利润如何转化为现金流，现金流需要多少资本投入，这些因素最终如何进入估值。

## 估值方法主线

### 1. 现金流折现法（Discounted Cash Flow，DCF）

现金流折现法（DCF）是核心绝对估值方法。至少完整走通：

`收入与利润率预测 → 税后经营利润 → 再投资 → FCFF → WACC → 显性期现值 → 终值 → 企业价值 → 净债务等调整 → 股权价值 → 每股价值`

- 主要采用 FCFF 与 WACC，并解释为何口径匹配。
- 必要时用 FCFE 作为补充，但不得混用 FCFF、FCFE、WACC 和股权成本。
- 明确预测期、终值方法、永续增长率、资本成本和关键经营驱动。
- 至少给出保守、基准、乐观三种情景及二维敏感性分析。
- 展示全部中间计算，不只给最终数字。

### 2. 相对估值法（Relative Valuation）

优先使用最常见且与长飞光纤经济特征相符的倍数：

- 市盈率（Price-to-Earnings Ratio，P/E）；
- 企业价值与息税折旧摊销前利润比率（Enterprise Value to Earnings Before Interest, Taxes, Depreciation and Amortization，EV/EBITDA）；
- 企业价值与息税前利润比率（Enterprise Value to Earnings Before Interest and Taxes，EV/EBIT）；
- 市净率（Price-to-Book Ratio，P/B），仅在净资产与资本回报具有解释力时使用。

必须统一可比公司的期间、币种、企业价值桥接、一次性项目和盈利口径。说明倍数差异来自增长、利润率、资本回报、风险还是会计口径，而不是机械套用均值。

### 3. 反向现金流折现法（Reverse DCF）

从 A 股或 H 股在明确日期的市场价格出发，反解市场价格隐含的收入增长、利润率、再投资效率或终值条件。

反向 DCF 的目标是回答“当前价格要求公司做到什么”，不是把反解结果冒充市场共识，也不是自动判断高估或低估。

### 4. 市盈率相对盈利增长比率（Price/Earnings-to-Growth Ratio，PEG）

说明 PEG 的定义、增长率选择、适用条件和局限，并使用长飞光纤及可比公司作辅助比较。PEG 只作为 P/E 与增长之间的粗略联系，不作为独立、精确的企业价值模型。

### 5. 必要的补充方法

只有当公司的业务结构或数据表明其能提供关键增量信息时，才加入：

- 分部加总估值（Sum of the Parts，SOTP）：不同业务的增长、利润率、资本强度或可比倍数明显不同时使用；
- 剩余收益或 P/B—ROE 框架：资产负债表与资本回报比自由现金流更具解释力时使用。

不要为了“覆盖所有方法”而罗列冷门模型。新增方法必须说明它解决了前四种方法无法解决的什么问题。

## 估值结果要求

本项目允许并要求计算长飞光纤的现实估值结果，但必须遵守以下规则：

- 输出估值区间、情景和敏感性，不制造伪精确的唯一正确价格。
- 同时展示企业价值、股权价值和每股价值，说明三者之间的桥接。
- A 股与 H 股分别显示币种、价格和必要的汇率换算，不默认两地价格应完全一致。
- 将 DCF、相对估值、反向 DCF 和 PEG 的结论并列，解释差异；不得简单平均不相容的方法。
- 结果是教学与研究计算，不构成评级、目标价承诺或买卖建议。

## 数据与证据规则

真实案例必须来源可追溯、计算可复算：

- 公司事实优先使用长飞光纤在交易所披露的中期报告、年度报告、公告和业绩材料。
- 市场价格、汇率、无风险利率、风险溢价、Beta、可比公司数据等必须记录来源、发布日期或抓取日期。
- 每个关键输入记录：`值、单位、币种、期间/时点、口径、来源地址、访问日期`。
- 已发生事实、公司指引、外部预测/市场共识、内部假设、派生计算和分析判断必须显式分层。
- 单家券商预测不得称为市场共识；无法确认的数据标记 `MISSING`，部分可用标记 `PARTIAL`。
- 半年度数据与全年数据不得直接混用。使用年化、LTM 或季节性调整时，必须展示方法并说明局限。
- 所有关键数字都应能从原始字段和公式复算；若不同来源冲突，保留冲突并解释选取依据。

## 写作要求

- 财务指标、估值方法和关键术语第一次出现时，必须同时写出中文名称、英文全称和标准缩写。
- 后续表格标题、公式标签和结果汇总应保留中英文或标准缩写，使中文含义与市场常用写法能够对应。
- 先讲经济含义，再讲术语和公式，并说明它在本案例中代表什么。
- 公式之后必须紧跟长飞光纤数字示例，避免长篇抽象定义。
- 明确区分“已核实事实”“计算结果”“假设”“推断”“尚未知”。
- 引用关键定义、公司数据和市场参数时提供可访问的来源地址，并说明来源支持什么。
- 不把复杂等同于专业；能用一张表或一个桥接关系说清楚的，不堆砌术语。

## 实施顺序

1. 建立 `practice/yofc/` 的目录和总路线。
2. 固定 2026 年中报及历史报告的来源、估值基准日和证券范围。
3. 从三大报表开始，完成常用财务指标的定义、手算和长飞实例。
4. 建立统一预测底稿和企业价值到股权价值的桥接。
5. 依次完成 DCF、相对估值、反向 DCF 和 PEG。
6. 仅在确有必要时补充 SOTP 或剩余收益框架。
7. 汇总方法差异、情景、敏感性、未知项和可复算结果。

在上述基础完成前，不把工作重心转向自动检查、Agent 工作流、交互界面或展示层。
