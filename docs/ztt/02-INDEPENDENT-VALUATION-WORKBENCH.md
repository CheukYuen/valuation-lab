# 中天科技独立估值工作台

> 这不是第二个目标价。它定义取得公司原始数据后，怎样把中天科技做成可复算估值。当前没有足够数据的格子保持 `MISSING`。

## 先看结论

中天科技应采用“分部经营预测 + FCFF DCF + SOTP交叉检查 + 反向DCF”的组合，但四种输出不平均：

- 分部预测回答三类业务分别赚什么钱；
- DCF回答经营利润扣除再投资后值多少；
- SOTP回答市场可能如何给不同业务定价；
- 反向DCF回答当前价格已经要求公司实现什么。

当前大摩报告只能提供集团总收入、EBITDA、净利润和部分DCF参数，无法完成独立目标价。

## 3. FCFF DCF

### What

把三个业务汇总后的税后经营利润转换成企业可分配现金，再折现。

### Why

大摩预测2026E净利润同比增长121.3%，远高于19.0%的收入增长。DCF可以检查利润率上升是否被扩产、库存、应收和项目履约现金占用抵消。

### How

`分部收入 -> 分部EBIT -> 集团EBIT -> NOPAT -> FCFF -> 企业价值 -> 股权价值 -> 每股价值`

### Data

目前只具备集团收入和EBITDA预测、报告WACC与永续增长。税率、折旧、Capex、营运资金、2027-2037 FCFF和净债务桥均为 `MISSING`。

## 4. SOTP交叉检查

### What

分部加总估值（Sum of the Parts，SOTP）先分别估三块业务，再扣净债务和其他索取权。

### Why

海洋工程、电力设备与光通信的周期、资本密度和可比公司不同，一个集团P/E会掩盖业务结构变化。

### How

`光通信价值 + 电力传输价值 + 海洋系统价值 + 非经营资产 - 净债务 = 股权价值`

### Data

必须有分部利润、分部资产或可分配现金流，以及同口径可比公司样本。当前均为 `MISSING`。没有这些输入时不能把集团净利润任意拆成三份。

## 5. 相对估值只做检查

报告价格42.85元除以ModelWare EPS，可得到2026E约22.8倍、2027E约17.6倍、2028E约14.2倍，与报告表格一致。目标价53.23元对应：

- 2026E EPS 1.88元：28.3倍；
- 2027E EPS 2.43元：21.9倍；
- 2028E EPS 3.01元：17.7倍。

这些是 `DERIVED` 的目标价隐含P/E，不是大摩的估值方法，也不是独立目标倍数。它们只能用于检查DCF结果对盈利要求是否过高。

## 6. 反向DCF

### What

固定当前股价和资本成本，反求市场价格需要的收入增长、利润率、再投资率或高增长持续期。

### Why

它不要求先相信大摩53.23元，可以直接问：42.85元已经计入了多少光纤提价、利润率扩张和海洋项目兑现？

### How

一次只反求一个核心变量：

1. 固定收入路径和再投资率，反求正常化EBIT利润率；或
2. 固定利润率和资本周转率，反求高增长持续年数；或
3. 固定经营情景，反求市场隐含WACC。

### Data

仍需当前净债务、税率、Capex/折旧、营运资金和业务正常化假设。反向DCF输出是“价格隐含条件”，不是预测或目标价。

## 7. 三情景只改变有因果依据的变量

| 变量 | 下行情景 | 基准情景 | 上行情景 |
|---|---|---|---|
| 光通信ASP | 普通光纤价格回落，特种产品放量慢 | 新合同提价兑现后逐步正常化 | 卖方市场更久、特种产品占比提升 |
| 有效产能 | 扩产快、竞争加剧 | 产能按计划爬坡 | 良率/认证约束延缓供给 |
| 海洋订单 | 海外订单推迟或成本超支 | 按里程碑确认 | 海外渗透和利用率超预期 |
| 电力传输 | 原材料传导不足 | 稳定增长 | 电网投资和产品结构改善 |
| 营运资金 | 存货/应收占用上升 | 随收入温和增长 | 预付款和回款改善 |

每个情景都要穿过 `收入 -> 利润 -> 再投资 -> FCFF`，不能只改目标倍数。

## 8. 完成条件

独立估值只有同时满足以下条件才算完成：

1. 历史报表与三业务分部数据能对上公司披露；
2. 光通信至少拆出普通与特种产品，海洋业务按订单转化而不是行业增速直接外推；
3. Capex和营运资金进入FCFF；
4. WACC公式、币种、估值日、净债务和股数口径闭合；
5. 终值利润率和资本回报率回到可持续水平；
6. DCF、SOTP、相对估值和反向DCF分别回答自己的问题，不平均结果。
