## 先记住三个边界

1. 中天科技不是“纯光纤股”。光通信、电力传输和海洋系统必须分开预测，再进入公司估值。
2. 报告中的2026E-2028E数据是 `BROKER-EST`，不是公司已经实现的数据。
3. 大摩披露了DCF框架，却没有披露逐年自由现金流。53.23元是报告目标价，不是本项目已独立复算的结果。

## 下一步

1. 取得公司2025年报和2026年半年报原文，建立三业务历史报表桥。
2. 补光纤/光缆、海缆、电力电缆的量、价、产能、订单与收入确认数据。
3. 用公司口径建立2026H2-2030分部预测，再做独立DCF、SOTP和反向DCF。
4. 将实际结果与大摩2026E-2028E预测逐期对照。
