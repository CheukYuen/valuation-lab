## 先记住三个边界

1. 中天科技不是“纯光纤股”。光通信、电力传输和海洋系统必须分开预测，再进入公司估值。
2. 报告中的2026E-2028E数据是 `BROKER-EST`，不是公司已经实现的数据。
3. 大摩与美银都披露了DCF框架，却没有披露完整逐年自由现金流和股权价值桥。53.23元、65元分别是两家报告目标价；本项目以公司原始报表、datahub快照和显式FCFF桥得到下行28.50元、基准41.75元、上行51.84元。

## 下一步

1. 继续把2026年实际结果与大摩2026E-2028E预测逐期对照。
2. 公司披露新的分部收入和毛利率后，替换当前集团层现金流假设。
3. 不平均三情景，也不把WACC/永续增长敏感性当成经营情景；相对倍数只用于交叉检查。
