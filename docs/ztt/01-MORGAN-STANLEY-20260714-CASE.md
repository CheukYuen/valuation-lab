# 摩根士丹利 2026-07-14 中天科技研报案例

> 本文复核报告中可见的经营预测和DCF参数。报告未披露2027-2037逐年自由现金流，因此本文明确停止在可验证边界，不反推53.23元目标价。

## 先看结论

大摩对中天科技使用企业自由现金流折现（Free Cash Flow to Firm Discounted Cash Flow，FCFF DCF），目标价53.23元，报告价格42.85元，对应24.2%的机械上涨空间。

报告的经营逻辑是：2026Q2利润预告略低，主要是出口特种光纤的收入确认节奏；2026Q3则受益于光纤需求、提价和产品结构改善。大摩预计收入从2025A的525亿元增至2028E的843.8亿元，ModelWare净利润从29.02亿元增至102.82亿元。

但估值只披露WACC 9.67%、永续增长2%和2027-2037估值期间，没有逐年FCFF、终值基数、折现时点、目标净债务或完整股权价值桥。因此：

- 经营预测可以做派生分析；
- DCF方法可以学习；
- 53.23元目标价的独立复算状态是 `MISSING`；
- 可见资本结构公式得到9.49% WACC，与报告9.67%相差0.18个百分点，状态为 `PARTIAL`。

1. 2026E收入只增长19.0%，净利润却增长121.3%，核心不是销量一项，而是ASP、产品结构和经营杠杆共同改善。

## 4. DCF是什么、为什么使用

### What：企业自由现金流折现

FCFF DCF估值的是全部经营资产，而不是直接给净利润乘一个倍数：

`企业价值 = 显性期FCFF现值 + 终值现值`

`股权价值 = 企业价值 - 净债务及其他索取权 + 非经营资产`

`每股价值 = 股权价值 / 稀释后股数`

其中：

`FCFF = EBIT × (1 - 税率) + 折旧摊销 - Capex - 营运资金增加`

### Why：中天的收入确认与投资支出不能只看利润

中天同时有光通信制造、输电产品和长周期海洋工程。订单、交付、收入确认、存货、应收账款和资本开支的时点可能不同。DCF能迫使分析者回答：利润何时变成现金、扩产要花多少钱、海缆项目要占用多少营运资金。

### How：完整复算链

1. 分别预测光通信、电力传输、海洋系统的量、价、收入和利润率；
2. 汇总为EBIT并计算税后经营利润；
3. 加回折旧摊销，扣除Capex和营运资金增加，得到逐年FCFF；
4. 用WACC折现2027-2037的FCFF；
5. 用正常化FCFF和永续增长率计算终值；
6. 从企业价值桥接到股权价值，再除以稀释后股数。

## 5. 估值参数复核

### 股权成本可闭合

`3.15% + 1.2 × 4.5% + 2.0% = 10.55%`

其中2.0%的中国风险溢价被直接加在CAPM结果上。公式可复算，但Beta和风险溢价的底层样本没有披露。

### WACC可见公式不闭合

若目标债务/资本为20%、股权/资本为80%，且5.25%已经是税后债务成本：

`可见WACC = 80% × 10.55% + 20% × 5.25% = 9.49%`

报告列示9.67%，差0.18个百分点。9.67%反推的债务权重约16.6%，不是报告写出的20%。可能存在未展示的精确权重或其他调整，因此本文标为 `PARTIAL`，不判定报告错误，也不将9.49%替换为报告参数。

### 目标价能派生什么，不能派生什么

- `53.23 × 3,413百万股 = 1,816.74亿元`，是按报告股数派生的目标股权价值。
- 报告当前市值1,462.45亿元、EV 1,347.28亿元，机械净现金为115.17亿元。
- 若仅为展示并假设净现金不变，目标EV约1,701.57亿元；这不是报告披露的DCF企业价值。
- 缺少逐年FCFF、终值FCFF和目标净债务桥，不能从这些派生值验证53.23元。

## 6. 产业信息的可用边界

报告第1页只提供方向：

- 2026年6月G.657现货价格环比小幅上涨，G.652.D环比持平；没有具体价格、样本和地区，属于 `BROKER-CHECK/PARTIAL`。
- 报告称光纤仍是卖方市场，中天选择客户并要求预付款；这对订单质量和现金流有利，但没有订单样本，属于 `BROKER-EST/PARTIAL`。
- 2H26中国移动新价格将明显提升；报告没有新中标价和份额，不能直接填入公司综合ASP。

不能把这些方向性描述当作完整行业供需表。产品规格、客户、合同、销量和确认时点仍需补证。
