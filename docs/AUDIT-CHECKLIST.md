# 分层审计清单

目标不是证明估值“绝对正确”，而是判断它是否值得继续使用。

每项使用四种状态：

| 状态 | 含义 |
|---|---|
| **通过** | 有证据支持，口径能够复核 |
| **警告** | 可能合理，但缺少解释或对结果影响较大 |
| **失败** | 已发现矛盾、错配或经济上不可行 |
| **无法确认** | 当前材料不足；不能擅自当作通过或失败 |

记录时必须同时写下“我看到了什么”和“它会怎样影响结论”。

## 第一层：六道快速门

先用 5–10 分钟筛查。不要一上来读目标价。

| 门 | 查什么 | 为什么可疑 | 还不能据此断言什么 |
|---|---|---|---|
| 1. 对象与分母 | 公司、证券、股本、库存股、每股分母是否对应 | 分母错会直接使每股结果失真；A/H 或增发尤其常见 | 看到多个股本口径不等于一定错，关键是各自用途是否解释 |
| 2. 时点、币种与单位 | 价格、汇率、现金、债务和财报日期能否对齐 | 异步数据可能漏掉现金流或资本变化；单位错可放大百倍 | 日期不同不自动无效，但必须有桥接或影响说明 |
| 3. 信息性质 | 六类信息（已发生事实、公司指引、外部预测、内部假设、派生计算、分析判断）是否分开；共识与单家预测是否区分 | 把假设写成事实会制造虚假的确定性 | 使用券商预测本身没有错，冒充事实才是问题 |
| 4. 利润到现金 | 利润是否经过税、资本开支、营运资金等变成现金流 | 利润增长可能被库存、应收或扩产吃掉 | 现金流短期下降不自动说明生意差，可能处于合理投资期 |
| 5. 敏感性与终值 | 是否展示关键假设区间、终值占比和正常化依据 | 单点会隐藏结果对 WACC、利润率和终值的依赖 | 缺表是披露警告，不单独证明底层计算错误；终值高也不自动无效 |
| 6. 方法匹配 | 方法是否适合商业模式和所处阶段 | 峰值 PE、亏损公司 PE、不可拆分的 SOTP 都可能失真 | 没有一种方法天然正确；辅助方法也可以提供量级校验 |

### 快速结论

- **停止使用**：对象/分母、币种/单位或核心计算口径已经确认失败，足以推翻输出。
- **带条件使用**：关键假设、现金流或时点存在警告/无法确认，方向可看但不能依赖单点。
- **可继续使用**：六道门无重大失败，关键警告已量化并进入敏感性；继续做深入审计。

“可继续使用”不是“估值正确”，更不是“股票便宜”。

## 第二层：深入审计清单

通过快速门后再做。原有18条纪律保留在这里，但按判断任务分组。

### 对象、时点与证据

| # | 检查项 | 失败或警告示例 |
|---|---|---|
| D1 | 股本关系与每股权利 | 总股本、流通股、扣库存股后股数静默混用；双重上市每股权利未核验 |
| D2 | 同一估值时点 | 价格是8月、资本结构是3月，中间现金流无人处理 |
| D3 | 币种和单位 | 港元报价直接接人民币报表；万元、百万元、亿元混用 |
| D4 | 原始存证 | 只有会变化的网址，没有冻结文件、时间戳或哈希 |
| D5 | 输出精度 | 输入约为20亿，输出却声称精确到0.01亿 |

### 报表与现金流

| # | 检查项 | 失败或警告示例 |
|---|---|---|
| D6 | 利润口径 | 归母净利、总净利、EBIT、EBITDA混用 |
| D7 | FCFF定义 | 正向模型逐项计算，反向模型改用未解释的固定转化率 |
| D8 | EV桥 | 现金、债务、租赁、少数股东权益来自不同报告期或重复处理 |
| D9 | OCF交叉检查 | `经营现金流 - Capex` 与 FCFF 差异无法解释 |
| D10 | 经营联动 | 收入、利润率、营运资金和Capex出现无机制解释的跳变 |

### 假设、终值与方法

| # | 检查项 | 失败或警告示例 |
|---|---|---|
| D11 | WACC来源 | 无风险利率币种不匹配；Beta没有数据；只给习惯值 |
| D12 | 终值正常化 | 直接把周期峰值利润率永久化 |
| D13 | 增长与再投资 | 长期增长没有相应资本投入；`g = 再投资率 × ROIC` 无法解释 |
| D14 | 情景机制 | Bear/Base/Bull只改净利润，没有量、价、成本和现金转化差异 |
| D15 | 反向DCF | 只报单点，不报替代组合；超过100%利润率仍当作普通数字 |
| D16 | 可比业务 | 用“同属一个行业”代替收入结构、周期和会计口径可比 |

### 输出纪律

| # | 检查项 | 失败或警告示例 |
|---|---|---|
| D17 | 概率和单点 | 主观概率没有依据却加权成精确目标价 |
| D18 | 结论边界 | 用股价、资金流或估值模型反向证明基本面；模型价值直接变成买卖动作 |

## 严重性怎么定

| 严重性 | 定义 | 处理 |
|---|---|---|
| **致命** | 已确认足以使核心输出失效 | 停止使用，修正后重算 |
| **重大** | 很可能改变方向、区间或最可引用结论 | 带条件使用并量化敏感性 |
| **次要** | 影响披露、精度或局部可回查性，不太可能单独翻转方向 | 记录并修复 |
| **暂无法确认** | 证据不足，影响大小也不确定 | 保持未知，不替模型补答案 |

严重性取决于对本次结论的影响，不由规则编号自动决定。同一个日期错配，在低现金流公司可能次要，在刚完成大额融资的公司可能致命。
