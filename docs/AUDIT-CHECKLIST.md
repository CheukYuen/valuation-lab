# 审计清单

这是本仓库的主工具。它不是用来**做**估值的，是用来**审**估值的——别人的研报、模型，以及你自己或 agent 产出的运算。

核心事实：**估值错误几乎不发生在数学里，发生在接缝上。** 口径、时点、分母、信息性质。接缝可以肉眼查，数学不必重做。

清单分两组。A 组不需要任何估值知识，只需要肯逐格核对；B 组需要一点背景，读完 [`FIVE-NUMBERS.md`](FIVE-NUMBERS.md) 再用。

---

## 用法

一份材料过三遍，不要一上来就读结论：

1. **先扫 A 组**，把不通过的项记下来。多数材料在这里就已经不值得往下读。
2. **在形成任何观点之前，先翻到敏感性表**。没有敏感性表的估值，退回。
3. **再过 B 组**，此时你已经知道该盯哪几个数。

记录写进 `cases/<案例>/worksheet.md`，不要只在脑子里过。写下来才知道自己哪条查不动。

## A 组 · 不需要估值知识（11 条）

| # | 查什么 | 不通过的样子 |
|---|---|---|
| A1 | **分母是哪个股本？** | 总股本、流通股、扣库存股后混用；每股数字与股本口径对不上 |
| A2 | **价格、汇率、财报是同一天吗？** | 价格是 8 月，资本结构是 3 月，中间四个多月的现金流没人交代 |
| A3 | **有敏感性表吗？** | 只有一个数。直接退回，不用往下看 |
| A4 | **终值占多少？** | 没披露；或超过 60% 却仍把七年明细表当作论据主体 |
| A5 | **情景之间改的是什么？** | 只改了收入和利润率两格。那不是情景，是三个数 |
| A6 | **每个数标了性质吗？** | 已发生事实、公司指引、市场共识、单家券商预测、作者自己的估计混在同一段话里 |
| A7 | **位数超过输入精度了吗？** | 输入是「约 20 亿」，输出是「1,393.73 亿」 |
| A8 | **有概率加权出的单点吗？** | `20%/50%/30%` 加权成一个目标价。概率哪来的？ |
| A9 | **关键输入能点回原始出处吗？** | 只有一个 URL，没有存下来的文件；或引用的接口按那个地址取不回当时的值 |
| A10 | **单位和币种全程一致吗？** | 万元/百万/亿元换着用；港元报价与人民币报表未声明折算方向 |
| A11 | **假设在前还是免责声明在后？** | 结论先行，假设塞进附录，最后补一句「本文不构成投资建议」 |

A1、A2、A9 这三条命中率最高。真实材料里出问题最多的就是分母、时点、存证。

## B 组 · 需要一点背景（7 条）

| # | 查什么 | 不通过的样子 |
|---|---|---|
| B1 | **折现率怎么来的？** | 无风险利率与报表币种不匹配；Beta 只写方法不给数据；权重用的市值正是模型说撑不住的那个 |
| B2 | **终值用的是正常化盈利还是最后一年盈利？** | 直接把显性期最后一年的利润率永续化——不管那一年是周期顶还是周期底 |
| B3 | **再投资率、增长、ROIC 自洽吗？** | `g = 再投资率 × ROIC` 不成立；或终值 ROIC 长期高于 WACC 却无解释 |
| B4 | **FCFF 定义在模型各处一致吗？** | 正向用 `EBIT(1−t)+D&A−Capex+ΔWC`，反向写死一个现金转化比例，然后拿两边的结果互相比较 |
| B5 | **EV 桥的加减项同期吗？** | 现金、债务、少数股东权益取自不同报告期；非经营资产既没扣也没说明为什么不扣 |
| B6 | **少数股东权益怎么扣的？** | 用账面值从一个前瞻现金流算出的 EV 里扣，两边口径不同却不提 |
| B7 | **反解报告了多组可行解和无解区域吗？** | 只给单点；解出来的利润率超过 100% 仍当作数字列表呈现，而不是当作「此价格无经济解」的结论 |

B4 和 B7 是最常见也最隐蔽的两条。它们不改变模型看起来对不对，只改变结论怎么读。

## 危险信号（不需要任何知识就能识别）

看到以下任何一条，先降低对整份材料的信任度：

- 单点目标价，尤其带小数点（「目标价 42.35 元」）
- 概率加权出的「综合价值」
- 情景之间只有净利润不同
- 没有敏感性表
- 结论在前、假设在附录
- 用股价走势、资金流、拥挤度证明基本面判断
- 「保守估计」出现三次以上但从不量化保守了多少

最后一条值得展开：**单个保守选择是美德，一叠保守选择是没披露的偏向。** 正确做法是把整叠反过来重跑一遍，看结论还站不站得住。见 `cases/01-yofc/knobs.py` 的实验 2。
