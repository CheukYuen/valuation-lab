# 野村 2026-08-21 长飞光纤研报案例

> 本文记录野村在长飞2026年中报披露当日使用了什么数据、如何解释二季度盈利跃升，以及怎样用单期远期P/E形成目标价。报告没有完整年度预测表，本文不会据标题或目标价反推不存在的经营模型。

## 先看结论

野村采用最直接的远期市盈率（Price-to-Earnings Ratio，P/E）方法：以2027财年每股收益（Earnings Per Share，EPS）9.75元乘以23.7倍目标P/E，得到231.075元人民币/股，再对应266港元目标价。

可见乘法可以独立复算，但报告没有披露人民币兑港币汇率。用目标价反推得到 `1 HKD = 0.868703 CNY`，这只是 `DERIVED`。23.7倍据称等于WIND H股线缆公司P/E中位数，但报告没有列公司名单、取样日、预测年度或统计过程，因此倍数来源只能标为 `PARTIAL`。

这是一份两页核心内容的业绩快评。它详细列出季度和半年度实际财务数据，但没有给出2026E-2028E收入、利润、毛利率、资本开支或现金流预测。除FY27 EPS外，不能把它写成一套完整经营预测。

## 6. 估值方法与过程

### What：远期P/E在做什么

远期市盈率法（Forward Price-to-Earnings Ratio，Forward P/E）用未来一个年度的每股收益（Earnings Per Share，EPS）乘以市场愿意给予的市盈率倍数：

`人民币每股价值 = 目标年度EPS × 目标P/E`

EPS是普通股股东口径的盈利，所以计算结果直接是每股股权价值，不是企业价值。它用一个倍数同时概括市场对增长、风险、资本回报、周期和利率的判断，优点是简洁，缺点是这些判断没有逐项展开。

### Why：野村为什么使用FY27 P/E

这是一份中报快评，重点是二季度提价和盈利超预期如何改变市场定价，而不是建立完整现金流模型。野村选择FY27 EPS，原因可以从报告方法表述中明确到两点：

1. FY27是目标价期限附近的远期盈利，可减少2026年只有部分年度实际结果造成的期间混合；
2. 23.7倍与其所称WIND H股线缆公司中位P/E一致，便于与市场上相似证券横向比较。

这种方法适合快速回答“若野村的FY27盈利实现，并按可比公司中位估值交易，股价是多少”。它不直接回答增长需要多少资本、利润能否变成现金，或2028年以后盈利是否回落。

### Data：野村实际使用了什么

| 输入 | 报告值 | 在公式中的作用 | 状态 |
|---|---:|---|---|
| FY27 EPS | 9.75元 | 未来每股盈利 | `BROKER-EST`；净利润和股数桥`MISSING` |
| 目标P/E | 23.7倍 | 每1元FY27盈利对应的价格 | 可比公司名单、取样日和统计过程`PARTIAL` |
| 目标价 | 266港元 | 最终港币输出 | 报告明示 |
| 人民币/港币汇率 | 未披露 | 把231.075元换为266港元 | 只能反推，`MISSING` |

报告第1页的2026H1和2Q26数据用于判断盈利变化，但没有展示它们如何逐步形成FY27收入、利润和EPS。历史事实是预测起点，不等于估值公式已使用所有历史表格字段。

### How：从FY27 EPS到港币目标价

完整可见链条只有三步：

`FY27 EPS → 乘23.7倍P/E → 人民币每股价值 → 汇率换算 → 港币目标价`

报告没有另做折现。不能擅自增加股权成本把FY27价值再折回，也不能把野村未披露的净利润、股数或可比样本反推成报告事实。

### 第一步：预测FY27 EPS

野村使用FY27 EPS 9.75元。报告没有给净利润和加权平均股数，因此EPS分子、分母桥均为 `MISSING`。

### 第二步：给予23.7倍目标P/E

`人民币每股价值 = 9.75 × 23.7 = 231.075元`

报告称23.7倍与WIND H股线缆公司P/E中位数一致，但没有提供：

- 可比公司名单及业务可比性；
- 使用FY26、FY27还是未来十二个月盈利；
- 价格与预测取样日；
- 中位数的原始倍数分布。

所以乘法已复算，倍数依据仍为 `PARTIAL`。

### 第三步：人民币换算港币

由231.075元和266港元反推：

`隐含汇率 = 231.075 ÷ 266 = 0.868703人民币/港元`

报告没有列示汇率来源或日期。这一数值仅用于重放目标价，不作为独立市场事实。

## 8. 当前使用等级

- **2026H1和2Q26结果：可用，但“调整后经营利润”除外。** 报告提供完整季度表，适合核对盈利拐点；只有调整后经营利润是 `BROKER-ADJUSTED`，与公司披露的营业利润和高盛的季度拆分都对不上。
- **经营预测：不可重建。** 除FY27 EPS外无年度经营模型，不得补造收入、利润率或现金流路径。
- **P/E乘法：可复算。** `9.75 × 23.7`闭合；可比样本和汇率桥不闭合。
- **目标价：部分可用。** 可以说明野村如何定价，不能声称266港元已被完整独立验证。
- **结论边界：** 这份快评适合研究“中报盈利超预期如何映射到单期远期P/E”，不适合研究完整周期现金价值。
