# 四家券商估值方法与本项目长飞案例对比

> 比较对象：杰富瑞2026-07-22、高盛2026-08-28、野村2026-08-21、摩根士丹利2026-08-23，以及本项目2026-08-24估值。各自信息集、股价、汇率和财务期间不同，本文保留原时点，不把所有结果重估到同一天。

## 先看结论

四家券商并不是用四种公式测量同一个不变对象：

- 杰富瑞把光纤主业、EverProX持股和多元业务分开，用分部加总估值（Sum of the Parts，SOTP）。
- 高盛把2030E每股收益用14.6倍市盈率（Price-to-Earnings Ratio，P/E）资本化，再用股权成本折回目标年。
- 野村直接用2027E EPS乘以23.7倍P/E。
- 摩根士丹利用剩余收益模型（Residual Income Model，RIM），理论上围绕账面价值、净资产收益率和股权成本估值。
- 本项目用企业自由现金流（Free Cash Flow to Firm，FCFF）折现，把经营利润、再投资、现金流、加权平均资本成本和终值接在同一条链上。

四家券商目标价从153.74到292港元，本项目DCF三情景为15.57到56.75港元。这个巨大差距主要来自2027年以后利润率能维持多久、增长需要多少再投资，以及目标倍数/终值如何处理，不应简单平均成一个“综合目标价”。

### 先统一“经营利润”的口径再横比

在比较利润路径之前有一个陷阱必须先排掉：高盛、野村和大摩三份报告都在历史列里放了 1H26 经营利润 **3,591 百万元**，但公司披露的 2026H1 营业利润是 **3,810 百万元**，按 `利润总额 + 利息费用 − 利息收入` 重建的报表 EBIT 是 **3,876 百万元**（见[财务指标章](01-FINANCIAL-METRICS.md)）。3,591 与两者都不相等，说明它是券商自己的历史调整口径，不是发行人披露的报表行。

更准确的说法是：**券商表内可以闭合，与公司报表之间的桥缺失。** 三家的 1H26 都满足 `毛利润 5,234 − 期间费用合计 1,643 = 经营利润 3,591`，这个小计在券商自己的表里是可复算的；高盛和野村的季度拆分虽不同（费用 704/939 对 498/1,145），但半年合计同样都是 1,643。缺的是 1,643 与公司报表各费用科目之间的完整调节桥——公司口径下 `毛利 5,234 − 营业利润 3,810 = 1,424`，与 1,643 相差 219，这 219 的构成没有披露。

因此季度拆分不同只能证明它不是同一条公司披露行，不足以推断“各家做了无法解释的调整”。本项目的记录是：**券商经营利润小计可复算，完整调整项目桥为 `PARTIAL`**。

因此本项目把这些行统一标为 `BROKER-ADJUSTED`——注意这是**对已发生期间的调整值**，不是 `BROKER-EST` 那种未来预测——并且：**跨券商比较“经营利润率”之前必须先各自调回公司披露的营业利润，或统一到同一套分析口径**；直接把三家的经营利润率并排放进一张表会得出无意义的结论。这不影响本文其余的目标价复算，因为四家的目标价公式都不使用这个数。

这里能看到三种周期判断：

1. **杰富瑞：2027E接近峰值，2028E开始明显回落。**
2. **高盛：收入和净利润一路增长至2032E，长期毛利率仍接近50%。**
3. **大摩：收入继续增长，但净利润和EBITDA在2027E见顶后回落。**

所以目标价差异首先是经营预测差异。即使给三家相同P/E，盈利路径仍会产生不同结果。

## 4. 每种估值方法的What、Why、How和Data

### 4.1 SOTP：先拆业务，再加总价值

**What：是什么。** 分部加总估值（Sum of the Parts，SOTP）是一个估值组织框架，不是一个固定公式倍数。它把不同业务分别估值，再加上上市持股和其他资产，扣除未分配的总部或资本结构项目。

**Why：为什么用。** 当一家公司同时拥有传统周期业务、高增长业务和金融性持股时，使用一个公司整体P/E会把不同风险和增长混在一起。长飞的光纤主业、EverProX持股和多元业务正属于这种情况。

**How：怎么算。**

`公司价值 = 光纤主业价值 + EverProX持股价值 + 多元业务价值`

杰富瑞又把光纤主业拆成P/B和P/E两条路径，再声称取平均。SOTP的难点不是加法，而是每一部分是否用对了利润、资产、倍数、净债务和股本，且没有重复计价。

**Data：用了什么。** 2028E主业账面价值29,061百万元、3.56倍P/B、2027E主业EPS 9.37元、14.1倍P/E、827.905百万股、EverProX每股价值8.22元、多元业务2.74元，以及人民币/港币换算。主业平均值、EverProX上游桥和多元业务基础仍不完整。

**它回答的问题。** “如果不同业务分别按杰富瑞选择的市场倍数计价，合计值多少？”它不直接回答整个公司未来能产生多少现金。

### 4.2 P/B：为账面资本定价

**What：是什么。** 市净率（Price-to-Book Ratio，P/B）是股权市场价值除以普通股账面净资产：

`P/B = 股权价值 ÷ 账面净资产`

反过来估值时：

`股权价值 = 预测账面净资产 × 目标P/B`

**Why：为什么用。** P/B适合资本投入较重、账面资产与生产能力关系仍较强的业务。它必须和净资产收益率（Return on Equity，ROE）一起看：长期ROE越高于股权成本，市场通常越愿意支付高于1倍的P/B。

**How：杰富瑞怎样算。**

`29,061 × 3.56 ÷ 827.905 = 124.96元/股`

**Data：用了什么。** 2028E光纤主业账面价值、参考2018年周期峰值的3.56倍P/B及公司股数。最敏感的不是除法，而是2028E分部净资产如何形成、3.56倍是否能在2028年维持，以及分部与合并股本口径是否一致。

**它回答的问题。** “市场愿意为预测期主业每1元账面资本支付多少？”它不单独说明这些资产能产生多少现金或ROE能维持多久。

### 4.3 Forward P/E：为目标年度盈利定价

**What：是什么。** 远期市盈率（Forward Price-to-Earnings Ratio，Forward P/E）用未来年度EPS乘以目标倍数：

`每股价值 = 目标年度EPS × 目标P/E`

**Why：为什么用。** 它适合盈利为正、市场已有可比公司和远期预测的场景，能快速把盈利判断翻译成价格。缺点是把增长、风险、资本强度和现金转换都压缩进一个倍数。

**How：两份报告怎样算。**

- 杰富瑞主业：`2027E主业EPS 9.37 × 14.1 = 132.12元/股`；
- 野村合并公司：`FY27 EPS 9.75 × 23.7 = 231.075元/股`。

**Data：用了什么。** EPS需要净利润和加权股数；目标P/E需要可比公司或历史估值分布。杰富瑞的EPS分母及历史倍数选择为`PARTIAL`，野村没有披露WIND可比公司名单、日期和倍数分布。

**它回答的问题。** “若目标年度盈利实现，并获得所选市场倍数，每股价格是多少？”它不回答盈利实现需要多少Capex和营运资金。

### 4.4 Discounted P/E：先算远期价格，再折回目标年

**What：是什么。** 折现P/E在普通远期P/E外再加一层时间价值：

`目标价 = 远期EPS × 目标P/E ÷ (1 + 股权成本)^年数`

**Why：为什么用。** 当分析师认为公司要到较远年份才进入代表性盈利阶段时，可以先在远期成熟年份定价，再折回十二个月目标价。折现解决的是“未来的钱不等于今天的钱”，不解决经营预测是否正确。

**How：高盛怎样算。**

`23.98 × 14.6 = 350.108元`

`350.108 ÷ 1.11³ = 255.996元`

再通过报告未披露、只能反推的汇率换成292港元。

**Data：用了什么。** 2030E EPS 23.98元、14.6倍P/E、11%股权成本、三年折现期和汇率。报告可见CAPM输入得到11.3%，目标倍数回归样本和汇率均缺失。

**它回答的问题。** “2030E盈利按特定倍数形成的未来价格，在2027E值多少？”它仍然不显式展示再投资和自由现金流。

### 4.5 RIM：账面价值加超额回报

**What：是什么。** 剩余收益模型（Residual Income Model，RIM）从当前账面净资产开始，只把净利润超过股东必要回报的部分作为额外价值：

`剩余收益 = 净利润 - 股权成本 × 期初账面价值`

`股权价值 = 当前账面价值 + 未来剩余收益现值 + 终值现值`

**Why：为什么用。** 它适合账面价值有经济含义、ROE和分红可以预测的公司，能够直接解释P/B为什么高于或低于1倍。对长飞而言，它把大摩预测的高ROE与11%股权成本放在同一框架中。

**How：完整过程。** 每年先用净利润和股息滚存账面价值，再用期初账面价值计算资本收费，得到剩余收益并折现；最后加入终值。若ROE最终等于股权成本，新增剩余收益会趋近零。

**Data：用了什么。** 大摩给出2026E-2028E净利润、ROE、3%无风险利率、1.0 Beta、8%股权风险溢价、11%股权成本、中期增长15%和永续增长2%。但期初普通股账面价值、逐年分红、账面价值滚存、显性期及终值桥均未披露，所以230港元无法完整复算。

**它回答的问题。** “公司账面资本未来能赚取多少超过11%机会成本的利润？”它不是把净资产机械乘一个P/B。

### 4.6 FCFF DCF：把经营利润转成现金价值

**What：是什么。** 企业自由现金流折现法（Free Cash Flow to Firm Discounted Cash Flow，FCFF DCF）估的是全部经营资产价值：

`NOPAT = EBIT × (1 - 税率)`

`FCFF = NOPAT - 再投资`

`企业价值 = 各期FCFF现值 + 终值现值`

`股权价值 = 企业价值 - 债务 - 少数股东权益 + 超额非经营资产`

**Why：为什么用。** 它强迫增长为资本投入付费，能区分“利润高”和“可分配现金多”。长飞处于扩产和高ASP周期，只看P/E容易忽略Capex、营运资金和产能退出困难，因此DCF适合作为本项目主经营价值框架。

**How：本项目怎样算。** 从分部收入和EBIT利润率得到NOPAT；用收入除以资本周转率推算期末投入资本；投入资本增加就是再投资；FCFF按WACC折现；终值让新增资本ROIC向WACC收敛；最后完成EV到股权价值及A/H汇率桥。

**Data：用了什么。**

| 输入层 | 本项目数据 |
|---|---|
| 已发生事实 | 2026H1收入98.09亿元、投入资本192.12亿元、债务95.25亿元、少数股东权益40.16亿元、非经营资产106.93亿元、完全摊薄股数8.2791亿股 |
| 内部经营情景 | 2026E收入182/195/209亿元；分部收入；2026H2及2027-2031年EBIT利润率 |
| 再投资 | 投入资本周转率0.92倍、必要现金率3% |
| 折现与终值 | WACC统一10.49%（按CAPM推导，Beta 1.052来自258周回归）；终值增长2.0%/2.5%/3.0%；终值EBIT利润率8%/16%/21% |
| 币种 | 2026-08-24人民币/港币汇率0.86542 |

**它回答的问题。** “这组经营、再投资和风险假设能产生多少现金现值？”它的弱点是当前0.92倍固定资本周转率无法完整表示ASP变化、扩产时滞和资产退出受限。

### 杰富瑞：SOTP

主业的可见两条路径为：

- `2027E主业EPS 9.37 × 14.1 = 132.12元`

简单平均应为128.54元，但报告列121.78元，缺6.76元解释。完整复算状态为 `PARTIAL/MISSING`。

### 高盛：2030E折现P/E

`23.98 × 14.6 = 350.108元`

`350.108 ÷ 1.11³ = 255.996元`

### 摩根士丹利：RIM

可复算：`3% + 1.0 × 8% = 11%`。

不可复算：230港元。报告没有展示当前账面价值如何滚存、逐年ROE/净利润怎样形成剩余收益、分红如何改变账面价值，以及终值如何处理。因此不能用目标价倒推一个“机械RIM”。

### 本项目：FCFF DCF

本项目先用经营假设生成现金流：

`收入 → EBIT → NOPAT → 再投资 → FCFF → WACC折现 → EV → 股权价值 → 每股价值`

| 情景 | 人民币/股 | 港币/股 | 终值占企业价值 |
|---|---:|---:|---:|
| 保守 | 13.47 | 15.57 | 47.3% |
| 基准 | 30.47 | 35.21 | 64.3% |
| 乐观 | 49.11 | 56.75 | 73.9% |

DCF结果低不等于公式更“保守”这么简单：项目让高增长承担资本投入和折现成本，并让终值ROIC向WACC收敛。其乐观情景2026H2 FCFF仍为负，体现盈利增长可能先消耗现金。

## 6. 方法之间真正的差异

### P/E方法隐藏了什么

高盛和野村直接资本化股东盈利。P/E不会显式显示：

- 为产生利润需要多少Capex和营运资金；
- 利润有多少能转为自由现金流；
- 峰值利润率何时回落；
- 目标倍数本身隐含的长期增长与风险。

高盛通过长预测期和折现率补了一部分时间问题，但再投资仍藏在EPS预测内部。野村只有单期EPS，隐藏程度更高。

### SOTP解决了什么、又缺什么

杰富瑞至少承认传统光纤、AI光连接、上市持股和多元业务不应使用同一倍数。这比公司整体机械套可比公司倍数更贴近业务结构。但没有可靠分部资产、利润、Capex、总部费用和税务时，拆分并不会自动提高准确度。

### RIM与DCF的关系

RIM从账面股权和超额ROE出发；DCF从经营资产和自由现金流出发。若会计关系、预测和折现率完全一致，两者理论上应收敛。大摩报告当前的价值在于展示P/B-ROE视角，而不是提供可独立重建的RIM表。

### 本项目需要吸收什么

最有用的组合不是平均目标价，而是把外部研究的长处接到项目链条：

`产业供需 → 销量、ASP、有效产能 → 收入 → 单位成本/利润率 → Capex与营运资金 → FCFF → DCF`

- 借杰富瑞补量价产能结构；
- 用高盛和大摩的长期利润路径做周期情景；
- 用SOTP检查业务异质性；
- 用P/E/P/B观察市场如何资本化盈利；
- 用Reverse DCF检查当前价格要求公司做到什么。

## 7. 为什么不能平均目标价

| 输出 | 回答的问题 |
|---|---|
| 杰富瑞153.74港元 | 分部远期盈利/账面价值按特定周期倍数值多少 |
| 野村266港元 | FY27 EPS按H股线缆公司中位P/E值多少 |
| 大摩230港元 | 账面价值加未来剩余收益值多少，但桥未披露 |
| 高盛292港元 | 2030E EPS按增长相关倍数资本化并折回值多少 |
| 项目DCF 15.57-56.75港元 | 一组经营、资本投入、WACC和终值假设能产生多少现金现值 |
| Reverse DCF | 当前市场价格隐含什么经营条件 |

这些不是独立测量同一温度的五支温度计。平均后既无法说明对应哪一年盈利，也无法说明再投资、折现率、分部范围和终值，因此不产生新的信息。

## 8. 当前结论

1. **经营分歧大于算术分歧。** 2027E以后是回落、见顶还是持续高增长，决定了目标价量级。
2. **高目标价共同依赖高利润资本化。** 高盛、野村和杰富瑞都以远期高盈利乘倍数；大摩则把高ROE转为剩余收益。
3. **本项目DCF显式收取增长成本。** 这是结果明显较低的主要经济原因。
4. **四家报告都不能完整独立复算。** 缺口分别位于SOTP桥、倍数/汇率、单期经营预测和RIM账面价值滚存。
5. **下一版项目模型应升级经营预测，而不是替换DCF公式。** 量价、有效产能、单位成本、Capex时序和营运资金应成为显性输入。
