# 高盛 2026-08-28 长飞光纤研报案例

> 本文记录高盛在 2026-08-28 使用了什么数据、怎样预测经营结果、怎样用远期折现市盈率形成目标价，并独立复算可见公式。它不是公司指引、市场一致预期或本项目自己的估值结论。

## 先看结论

高盛没有使用现金流折现法（Discounted Cash Flow，DCF）。它先预测长飞 2030 年每股收益（Earnings Per Share，EPS）为 23.98 元，给予 14.6 倍市盈率（Price-to-Earnings Ratio，P/E），再用 11% 股权成本折回目标价时点，给出 292 港元的十二个月目标价。

可见公式只能复算到 255.996 元人民币/股；要重放 292 港元，还需要反推 `1 HKD = 0.876698 CNY`。报告没有列示该汇率来源。另一个明确缺口是：报告写股权成本为 11%，但其列示的资本资产定价模型（Capital Asset Pricing Model，CAPM）输入实际得到 `3.5% + 1.2 × 6.5% = 11.3%`。按 11.3% 折现，在同一隐含汇率下目标价约为 289.65 港元。

经营预测方面，高盛比野村和本期大摩快评更完整，但比杰富瑞的量价产能模型更偏财务结果：它预测产品收入、毛利率和利润，却没有展示销量、有效产能、单位成本、资本开支及营运资金的完整联动。

## 6. 估值方法与过程

### What：折现P/E在做什么

折现市盈率法先在一个较远年度用市盈率（Price-to-Earnings Ratio，P/E）把每股收益（Earnings Per Share，EPS）变成“未来时点的每股股权价值”，再用股权成本折回目标价时点：

`目标价时点人民币价值 = 目标年度EPS × 目标P/E ÷ (1 + 股权成本)^折现年数`

它估的是普通股每股价值，不是企业价值（Enterprise Value，EV）。EPS已经扣除了利息、税和少数股东影响，因此算完后不能再机械减债务，否则会重复扣除资本结构影响。

白话说，高盛先问“如果2030年公司赚到23.98元/股，市场愿意给14.6倍，那么2030年值多少”，再问“这笔2030年的价值折回2027年值多少”。

### Why：高盛为什么用2030E折现P/E

高盛认为长飞的价值来自AI数据中心产品组合升级和较长期增长，而2026-2027年仍受价格突升和周期波动影响。选择2030E有两个作用：

1. 把估值锚放到更成熟的盈利年份，减少只看2026年单季高毛利的影响；
2. 让目标倍数与下一年度净利润增长的可比关系发挥作用。

但这不等于方法自动更长期、更稳健。2030E EPS本身包含四年以上预测误差，14.6倍又包含可比公司和增长关系假设；折现只能处理时间价值，不能消除经营预测错误。

### How：从预测盈利到港币目标价

完整链条是：

`2030E收入与利润率 → 2030E净利润 → EPS → 目标P/E → 2030E人民币价值 → 股权成本折现 → 2027E人民币价值 → 汇率 → 港币目标价`

其中前半段依赖高盛经营预测，后半段才是估值公式。不能只复算最后三步就说2030E EPS已经验证；同样，不能因为EPS预测有争议就说乘法或折现公式本身错误。

### 第一步：预测2030E EPS

高盛预测2030E归母净利润18,175百万元、EPS 23.98元。二者隐含约758.0百万股，低于公司2026H1期末总股本827.905百万股。报告没有给出EPS股数桥，因此标为 `PARTIAL`。

### 第二步：给予14.6倍目标P/E

`2030E每股价值 = 23.98 × 14.6 = 350.108元`

高盛称14.6倍来自可比公司P/E与下一年度净利润同比增长的相关关系，但没有披露可比公司名单、样本点、回归方程、拟合优度和取样日，故倍数来源为 `MISSING`。

### 第三步：折回2027E目标时点

报告第3页写明用11%股权成本从2030E折回2027E：

`折现价值 = 350.108 ÷ (1 + 11%)³ = 255.996元`

第2页却写“discount back to 2030E”，与第3页方法说明和三年折现算术不一致。本文按第3页可复算表述重放，但保留第2页文字冲突。

### 第四步：人民币换算港币

报告没有列汇率。由255.996元和292港元反推：

`隐含汇率 = 255.996 ÷ 292 = 0.876698人民币/港元`

使用该隐含汇率可以重放292港元，但这是 `DERIVED`，不是报告明示的汇率事实。

## 8. 当前使用等级

- **历史与二季度结果：可用。** 与公司中报同一信息集，但报告内部的净利润环比文字和季度表存在基期差异。
- **经营预测：部分可用。** 产品收入和利润路径完整到2032E，但缺销量、有效产能、单位成本、Capex和营运资金桥。
- **折现P/E公式：部分可复算。** EPS、倍数和折现率可见；汇率、倍数回归和折现文字冲突使完整独立复算仍为 `PARTIAL`。
- **长期判断：高度依赖单家预测。** 2032E接近50%的毛利率是高盛长期价值的核心输入，不能当作公司指引或市场共识。
- **结论边界：** 可以用来研究“长周期EPS如何被P/E资本化并折回”，不能把292港元当作本项目验证后的合理价值。
