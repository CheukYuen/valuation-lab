## 证据标签

- **已披露事实**：可直接定位到上表原始报告的数字或文字。
- **派生计算**：使用已披露事实和明示公式计算。
- **分析口径**：为了进行比较或估值而选择的调整方法，不是公司披露值。
- **单家券商预测**：外部机构在特定日期作出的预测；可以比较和复算，但不能冒充公司事实、公司指引或市场共识。
- **MISSING**：当前正式来源不足以支持的数据。
