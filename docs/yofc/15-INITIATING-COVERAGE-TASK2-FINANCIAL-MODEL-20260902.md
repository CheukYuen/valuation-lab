> 本文只建立可追溯的静态财务模型，不给目标价或投资评级。估值路径继承已审计的 [12 号 Wind DCF](./12-WIND-DCF-20260902.md)，相对估值参照 [13 号 Wind Comps](./13-WIND-COMPS-20260902.md)，公司定性背景参照 [14 号 Task 1](./14-INITIATING-COVERAGE-TASK1-COMPANY-RESEARCH-20260902.md)。

## 模型摘要与使用边界

1. **FCFF工作模型采用④隐含正推法EBIT。** 工作模型为96.00 / 162.53 / 244.61元，基准计算值162.53元，属于 `PROJECT-ASSUMPTION/PARTIAL`；③ Wind一致预测EBIT路径85.48 / 151.31 / 233.45元保留为直接数据交叉检查。C1未通过只证明两条序列不能混用，不能证明③错误或④正确。
2. **选择④是口径与可审计性的工作决策。** 2026E和2028E直接出现归母净利高于EBIT，三年均未通过条件桥；2026E隐含H2 EBIT降至H1的78.6%，而H2归母净利升至H1的126.0%；使两条序列同时成立所需非经营净额约23.42 / 29.08 / 52.02亿元，显著高于历史−1.97至+5.19亿元。④把归母占比、税率、净利息和非经营净额显式列出，并与历史正推法EBIT和FCFF口径一致，因此用于三表和DCF；但这些桥参数固定外推仍不能升级为合理价值或目标价。
3. **“完整三表”不等于虚构精细度。** 预测期没有可靠的应收天数、存货天数、逐项债务计划、并购计划及递延税预测。本文让应收、存货、应付按 2026H1 结构分配，债务保持不变，股利率设为归母净利润的 30%；资产负债表未单独预测的负债归入“其他负债及平衡项”，并保留 `PARTIAL` 标签。
4. **现金不是被隐藏的补数。** 预测现金从 2025A 货币资金出发，由合并净利润、D&A、狭义 ΔNWC、Capex、分红及净融资滚存；资产负债表直接引用同一现金结果。历史“现金及现金等价物”与“货币资金”并非同一会计口径，2026H1 的约 0.48 亿元差额不被静默抹平。
5. **有效税率与 DCF 税率分开。** 利润表沿用 2026H1 有效税率 16.23%；FCFF 的正常化经营税率固定为 20%。前者用于净利润桥，后者用于 NOPAT，不得混用。

证据标签沿用项目统一规则：`WIND-FACT`、`REPORT-FACT`、`COMPANY-CITED`、`BROKER-VIEW`、`DERIVED`、`PROJECT-ASSUMPTION`、`PARTIAL`、`MISSING`。2026-09-04 的 Wind 更新只在限制中说明，不进入本模型。
