# 摩根士丹利 2026-08-23 长飞光纤研报案例

> 本文记录摩根士丹利在长飞2026年中报后使用的财务数据、经营预测和剩余收益模型参数，并复核所有可见公式。报告没有披露完整剩余收益估值表，因此本文明确停止在可验证边界，不反推230港元目标价。

## 先看结论

摩根士丹利使用剩余收益模型（Residual Income Model，RIM），不是市盈率目标价，也不是企业自由现金流折现。RIM先从当前账面净资产出发，再加未来“净利润超过股权资本机会成本”的现值：

`股权价值 = 当前账面净资产 + 未来剩余收益现值`

报告披露股权成本11%、中期增长15%和永续增长2%，其中股权成本可以完整复算：`3% + 1.0 × 8% = 11%`。但报告没有披露期初账面价值、逐年剩余收益、分红率/账面价值滚存、显性期长度、终值桥和汇率，因此230港元目标价为 `MISSING` 级别的完整复算，而不是算术错误。

经营预测显示大摩预计2026E-2028E收入持续增长，但ModelWare净利润在2027E达到127.30亿元后于2028E回落到114.35亿元。也就是说，大摩不是把2026H1利润率无限外推；它同时假设中期高增长和后续盈利正常化。

## 6. RIM是什么、为什么使用

### What：剩余收益

剩余收益是净利润扣除股东要求的资本机会成本：

`当期剩余收益 = 当期净利润 - 股权成本 × 期初普通股账面价值`

若公司ROE等于股权成本，新增账面资本只赚到必要回报，剩余收益为零；若ROE持续高于股权成本，超额部分才增加账面价值之上的估值。

### Why：适合从P/B和ROE理解价值

长飞是资产和资本投入较重的制造企业，报告同时预测P/B、ROE和净利润。RIM能直接回答：“预测ROE高于11%股权成本的部分能持续多久、值多少钱？”

这与DCF关注自由现金流不同，但在会计干净盈余关系成立、预测一致时，两种模型理论上应指向相同股权价值。差异来自输入，而不是公式天然互斥。

### How：完整估值桥

若使用常见的干净盈余关系，逐年计算应为：

`期末账面价值 = 期初账面价值 + 净利润 - 股息及其他直接股东分配`

`当年剩余收益 = 净利润 - 股权成本 × 期初账面价值`

`股权价值 = 期初账面价值 + 各年剩余收益现值 + 终值剩余收益现值`

如果终值使用永续增长，常见形式是：

`终值 = 下一期剩余收益 ÷ (股权成本 - 永续增长率)`

这说明RIM不是简单的“净资产 × P/B”。P/B是结果表现，真正创造账面价值以上估值的是ROE超过股权成本的持续时间和幅度。若ROE最终降到11%股权成本，新增剩余收益会趋近零。

完整RIM至少需要：

1. 估值日普通股账面价值；
2. 每年净利润或ROE；
3. 分红率及账面价值滚存；
4. 每年股权成本；
5. 显性期长度；
6. 终值阶段剩余收益增长或ROE收敛；
7. 人民币股权价值换算港币的汇率。

报告只披露第4项和两个增长参数，其他关键桥未展示。
