# 四家券商长飞光纤产业信息对比

> 本文只比较杰富瑞、高盛、野村和摩根士丹利四份研报当时明确写了什么。CRU价格、公司扩产、运营商招标和管理层观点没有在本轮另行联网核验，因此不会从“券商报告中的说法”升级为已独立验证的产业事实。

## 先看结论

四家报告对2026年供需紧张和AI需求方向大体一致，真正分歧在紧缺能持续多久：

- **杰富瑞最担心供给。** 它列出19,400吨宣布扩产，预计2026年ASP可能见顶、2027-2028年新增产能消除短缺。
- **高盛更强调扩产落地延迟。** 它也预计供给增速高于需求、2028E开始略过剩，但认为新进入者的工艺、良率、原材料和设备交期会使有效供给爬坡更慢，因此2026H2价格仍高。
- **野村最乐观但最少量化。** 它把二季度盈利跃升归因于AIDC需求、短缺和提价，却没有ASP、扩产或招标数字。
- **大摩给出需求规模，不给供给表。** 它转述2026年全球需求超过6.70亿fiber-km、数据中心需求增长69%，同时把非理性扩产列为下行风险。

这意味着“都看好AI光纤”不等于预测相同。估值真正敏感的是：传统与AI产品各自ASP、宣布产能转为合格有效产能的时间、运营商集采价格，以及高毛利产品能否持续放量。

## 1. 证据标签与阅读规则

| 标签 | 含义 |
|---|---|
| `COMPANY-ACTUAL` | 已披露历史结果 |
| `COMPANY-COMMENT` | 券商转述公司或管理层观点，本文未取得完整底层记录 |
| `BROKER-EST` | 单家券商预测或分析判断 |
| `BROKER-CHECK` | 券商行业调研、CRU或渠道信息，底层样本未取得 |
| `DERIVED` | 用报告数值进行计算 |
| `PARTIAL` | 有方向或部分数据，但口径、样本或落地状态不完整 |
| `MISSING` | 报告没有提供 |

三个必须保持的边界：

1. 宣布扩产不等于建成产能，更不等于通过良率、认证并可销售的有效产能。
2. 运营商集采最高限价或中标价不等于全公司综合ASP，也不代表G.657、HCF、海外和AI专用光纤价格。
3. 券商引用公司管理层或第三方数据，不等于本文已经取得原始会议纪要、招标公告或CRU数据库。

### 为什么杰富瑞146元与高盛85.7元不能直接判定冲突

- 杰富瑞146元是其2026E预测序列中的“光纤ASP”，还区分国内和出口；高盛85.7元是其引用CRU的中国G.652.D月度价格。
- 产品等级、地区、合同类型、含税口径、国内/出口和时间加权方式可能不同。
- 没有两家完整口径定义前，只能记录数值差异，不能说其中一家算错。

### 对项目模型的要求

至少拆分：

`运营商普通光纤 / G.657 / HCF及AI专用光纤 / 海外光纤`

每类分别记录销量、合同价格或ASP、币种、期间和证据状态。不能用80元集采限价覆盖所有产品，也不能用150元以上特种光纤长协价覆盖传统业务。

### 主要分歧

- 杰富瑞与高盛都认为长期供给增速快于需求，并把转折点放在2028年前后。
- 杰富瑞预测盈利更早回落；高盛虽然承认2028E供给略过剩，却仍预测2032E毛利率约49.7%。这说明高盛长期利润还依赖产品结构、定价能力或成本优势，而不只是总量供需。
- 大摩和野村的需求判断支持景气，但没有足够供给输入判断紧缺持续期。

## 7. Capex与扩产现金成本

只有杰富瑞提供明确Capex序列：

- 经营假设表2026E-2032E：1,600、1,600、1,500、1,400、1,200、900、900百万元；
- 现金流量表PPE及无形资产Capex：1,830、1,830、1,716、1,601、1,373、1,030、1,030百万元。

两条序列方向一致、范围不同，缺少逐项调节，状态为 `PARTIAL`。高盛、野村和本期大摩报告均没有Capex预测。

这正是券商P/E/RIM目标价与项目DCF的关键接口：扩产和营运资金若不显式进入现金流，ASP上涨形成的利润可能被过快资本化。

## 9. 当前结论

1. **2026年价格高企有多家报告交叉印证，但具体ASP不可直接拼接。** 产品等级和合同口径不同。
2. **扩产方向没有争议，落地速度有争议。** 杰富瑞偏快、高盛强调工艺和设备时滞。
3. **2028年前后是共同关注的供需转折点。** 但高盛长期利润率仍显著高于杰富瑞，说明产品结构假设不同。
4. **招标数据最不足。** 只有价格线索，没有量、份额和收入确认桥。
5. **项目最需要补的是有效产能，而非宣布产能。** 应把建设、设备、良率、认证和客户导入转成逐年概率或产能利用率，再进入收入与Capex。
