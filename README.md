# valuation-lab

用 7 天、约 6 小时，从零理解估值、完成一套简化估值，再学会检查估值是否可靠。

这里不要求你写代码，也不会一开始就让你预测七年财务。课程先用小模型讲清价值怎样从经营和现金流产生，再把计算放进真实材料里检查。你要练成四种能力：

1. 看懂估值对象、方法、关键输入和公式；
2. 检查利润如何变成现金，打通 `EBIT → FCFF → EV → 股权价值 → 每股价值`，完成最小 DCF；
3. 判断 DCF、PE、PB、EV/EBITDA、SOTP 等方法何时适用；
4. 找到控制结果的关键假设和终值，检查时点、股本、单位、来源和假设，并说清什么还不能确认。

完成课程后，你应能交出两样东西：

- 一套写明输入、假设、公式、结果和敏感性的简化估值；
- 对一份估值材料给出有证据的检查结论。

检查结论使用三档等级：

| 结论 | 含义 |
|---|---|
| **可继续使用** | 方法、口径和关键假设基本合理，可以进入更深入研究 |
| **带条件使用** | 方向可以参考，但存在会改变结论的重要缺口 |
| **停止使用** | 对象、时点、现金流、方法或计算口径存在严重问题 |

这三档评价的是**估值材料的可靠性和可用性**，不是股票是否值得买。课程中的每股价值是教学计算，不是现实证券目标价。

## 从这里开始

互动版入口是 [`web/index.html`](web/index.html)，纯文字入口是 [`course/README.md`](course/README.md)。你不需要编写代码，只需要按课程指示运行现成命令。

| 天 | 主题 | 时间 | 过关能力 |
|---|---|---:|---|
| 1 | 估值到底在算什么 | 75 分钟 | 理解估值怎样把事实、预测和假设翻译成价值 |
| 2 | 亲手打通价值桥 | 65 分钟 | 从 EBIT 算到 FCFF、股权价值和每股价值 |
| 3 | 检查估值输入 | 35 分钟 | 核对对象、时点、币种、单位和来源 |
| 4 | 完成最小 DCF | 45 分钟 | 把现金流折现为价值，并读懂敏感性和终值 |
| 5 | 反向 DCF | 45 分钟 | 把价格翻译成可质证的经营要求 |
| 6 | 方法适不适合 | 40 分钟 | 判断 DCF、PE、PB、EV/EBITDA、SOTP 的角色 |
| 7 | 长飞综合练习 | 60 分钟 | 解释、复算并检查一份真实复杂估值材料 |

每课含一个必做的运行环节（约 5 分钟，已包含在上表时间内）：先写计算或方向判断，再运行脚本对答案。

开始前做 [`入门测验`](course/PRETEST.md)。完成第七课后做 [`毕业测验`](course/POSTTEST.md)。毕业标准是至少答对 8/10、七个运行环节全部跑过，并完成一页“估值解释 + 检查结论”。

遇到陌生词先查 [`白话术语表`](docs/GLOSSARY.md)。审材料时使用 [`分层审计清单`](docs/AUDIT-CHECKLIST.md)。

学习节奏与主动回忆方法见 [`快速科学学习法`](docs/LEARNING-METHODS.md)。

## 你不需要先准备什么

- 不需要推导 WACC；
- 不需要一开始就独立预测多年收入和利润；
- 不需要自己写程序；
- 不需要搭建可直接用于正式投资决策的大型 DCF；
- 不需要读完估值教科书。

课程会带你完成最小价值桥和最小 DCF。重点不是背出一个“合理价格”，而是理解价值怎样形成，再判断结果是否站得住。

## 每课的运行环节

每课一条命令，用来复算你已经写下的计算或方向判断——不是替你学习。

```bash
python3 lab/record_contract.py    # 第 1、3 课
python3 lab/bridge.py             # 第 2 课
python3 lab/mini_dcf.py           # 第 4 课
python3 lab/reverse.py 300        # 第 5 课
python3 lab/methods.py            # 第 6 课
python3 cases/01-yofc/knobs.py    # 第 7 课
```

全部只使用 Python 标准库，可离线运行。它们帮助你核对公式、方向、敏感性和记录完整性；其中产生的价值数字只属于明确假设下的教学练习。互动版页面调用与这些脚本同一套公式，数字必须一致。

维护者运行全部自动检查：

```bash
python3 -m unittest discover -s tests -v
```

## 与 investment-research-copilot 的关系

`investment-research-copilot` 做真实研究并产出估值运算；本仓库先训练人理解和完成简化估值，再训练人检查这类真实输出。

`cases/01-yofc/frozen/` 是来源提交 `b7c2da0` 的冻结副本。冻结文件不修改、不跟随来源更新，避免教学答案随模型变化。两仓库单向依赖，本仓库不把教学结论同步回研究仓库。

## 边界

本仓库可以在虚构案例或明确假设下计算教学用企业价值、股权价值和每股价值，但不输出现实证券的实时目标价、评级、仓位、买卖动作或交易时点。模型可用，不等于证券便宜；模型有缺口，也不自动等于证券昂贵。
