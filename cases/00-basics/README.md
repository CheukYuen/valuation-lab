# 入门案例：一次只找一个错误

六家公司完全虚构，数字只用于教学。每题先写：

```text
状态：通过 / 警告 / 失败 / 无法确认
使用等级：可继续使用 / 带条件使用 / 停止使用
证据：
影响：
还不能断言：
```

完成后再看 [`答案`](answer-key.md)。

## 案例1：错股本

甲公司模型计算股权价值100亿元。公司在估值日前完成增发，外部普通股由5亿股增至10亿股。模型仍使用5亿股，给出每股价值20元。

你只需要判断：这个每股输出能否使用？

## 案例2：错时点

乙公司估值使用8月31日股价，但现金和债务来自上一年12月31日。期间公司完成50亿元债券发行和30亿元现金收购。模型没有做任何桥接。

你只需要判断：当前股权价值桥能否使用？

## 案例3：利润不等于现金

丙公司预计EBIT由20亿元升至30亿元，模型因此把FCFF也由20亿元升至30亿元。同期扩建工厂需Capex 12亿元，库存和应收合计增加8亿元，模型未处理这两项。

你只需要判断：利润到现金的桥是否成立？

## 案例4：峰值永久化

丁公司产品价格暴涨，当年EBIT margin由历史8%升至25%。模型将25%作为终值利润率永久延续，但没有讨论新增供给、产品价格或历史周期。

你只需要判断：终值利润率是否有足够基础？

## 案例5：隐藏终值

戊公司DCF给出EV 200亿元，其中终值现值160亿元。报告只展示未来五年收入表，没有披露终值占比，也没有WACC和终值增长敏感性。

你只需要判断：是否可以把200亿元当作稳健单点？

## 案例6：方法错配

己公司是一家银行。模型把客户存款全部视为普通有息债务，从工业公司式EV中扣除，再用EV/EBITDA与制造业公司比较。

你只需要判断：主方法是否匹配银行的商业模式？
