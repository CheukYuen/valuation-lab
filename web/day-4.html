把现金流折现成价值 · 第 4 课

完成最小 DCF

把现金流折现为企业价值和股权价值。先预测方向，再一次只动一个输入，并让 FCFF终值倍数与永续增长在分母对齐后互译。〔D4-S1〕 〔D4-S2〕

一句话速览

切换终值写法等于切换远期假设。2% 永续增长隐含 14.6 倍第7年FCFF；10 倍第7年FCFF隐含约 -0.91%。

01 · 五个控制杆

真正控制结果的不是某一个格子

01起点现金

现在大致能产生多少FCFF。

02增长

收入、利润和现金以多快速度变化。

03持续时间

较高增长或利润能维持几年。

04远期状态

明细预测结束后的增长、利润和资本回报。

第五个控制杆是折现率：未来现金折回今天时要求的回报。五个杆一起决定价值，不要只盯终值那一个数。

03 · 负对照

高终值占比不等于模型失效

占比高，是质证信号

表示更多价值来自遥远未来。要检查远期现金、折现率和是否持续经营。

占比高，不是自动失败

持续经营公用事业终值占比74.1%，但远期假设已写明并可质证，当前不降级。特许等有限寿命资产不能用 Gordon。不披露占比才是缺陷。

06 · 一页验收清单

离开本课前核对这六项

  • WACC > 永续增长率 是否成立，模型在不成立时是否拒绝打印？（D11）
  • 终值用的是永续增长还是FCFF终值倍数，另一种写法的隐含值是否同时披露？分母是否真是第n年FCFF？（D12）
  • 终值利润率是否是可持续的远期状态，而不是当前峰值？（D12）
  • 终值现值占EV的比重是否披露？（D12）
  • Bear/Base/Bull 是否回到量、价、成本、Capex和现金转化？（D14）
  • 输出精度是否超过输入本身能支持的精度？（D5）

def value(p):
    if p["discount_rate"] <= p["terminal_growth"]:
        raise ValueError("折现率必须大于永续增长")
    flows = [p["base_fcf"] * (1 + p["growth"]) ** t for t in range(1, n + 1)]
    explicit_pv = sum(f / (1 + r) ** t for t, f in enumerate(flows, start=1))
    terminal_value = flows[-1] * (1 + tg) / (r - tg)
    terminal_pv = terminal_value / (1 + r) ** n
    ev = explicit_pv + terminal_pv
    return {"enterprise_value": ev, "equity_value": ev - p["net_debt"], …}
