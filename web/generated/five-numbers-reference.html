DCF 的五个控制杆

这是第4课的可选补充，不是入门前置知识。陌生术语先查 GLOSSARY.md。

五个控制杆

不管模型有多少个工作表，DCF 最终都离不开：

控制杆人话常见名称
起点现金现在大致能产生多少自由现金FCF / FCFF
增长现金流以多快速度变化收入增速、利润率路径
持续时间较高增长或利润能维持多久显性期、竞争优势期
远期状态明细预测结束后的正常经营终值、永续增长、终值ROIC
折现率未来现金折回今天时要求多高回报WACC、贴现率

看不懂模型时，不必先读全部公式。先找到这五个控制杆以及各自来源。

敏感性回答什么

敏感性不是用来找“正确数字”，而是观察：哪个合理变化最能改变结论。

运行可选实验：

python3 lab/mini_dcf.py

默认虚构案例中，折现率由9%升至10%，股权价值下降约14.6%；起点现金、增长和终值也会影响结果。这只是该组输入下的表现，不能推广成“所有估值都由折现率决定”。不同期限、债务和商业模式会得到不同排序。

怎样读终值占比

终值占比 = 终值现值 ÷ 企业价值

占比越高，结论越依赖显性期结束后的利润率、增长、资本回报和折现率。

可以把60%当作提醒自己停下来质证终值的经验线，但不能当作统一合格线：

  • 稳定、长寿命资产可能天然有较高终值占比；
  • 技术和竞争格局快速变化的公司，高终值占比通常更难支撑；
  • 拉长显性期可能只是把远期假设挪进明细表，并不自动提高可信度。

反向 DCF 的正确读法

正向 DCF 问“按我的预测值多少”；反向 DCF 问“在这组模型约定下，当前价格要求什么”。

python3 lab/reverse.py 300

必须同时看到：

  1. 使用了什么折现率、现金流定义和终值；
  2. 增长、利润率、持续时间之间有哪些替代组合；
  3. 是否出现经济上难以解释的区域；
  4. 隐含要求能否与公司历史、同行和经营机制比较。

反向 DCF 没有把未来预测变成事实。它只是把争论从“目标价是多少”改成“哪些经营条件才能解释价格”。

方法与生意的匹配

业务特征常用主方法或校验需要警惕
周期品周期正常化、反向DCF、情景分析峰值利润乘历史PE
稳定现金流DCF、股息折现折现率或终值缺少敏感性
平台/订阅单位经济、长期利润率、情景DCF用短期亏损直接否定价值
重资产DCF、EV/EBITDA与资本回报结合EBITDA忽略Capex和营运资金
银行/保险PB/ROE、剩余收益等生搬普通工业公司的FCFF
早期/无盈利单位经济、里程碑和宽区间情景用遥远假设制造精确DCF

这些是起点，不是机械规则。最终仍要检查数据是否足以支撑所选方法。
