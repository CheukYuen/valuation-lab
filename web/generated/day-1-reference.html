第1天：模型到底在说什么

本课目标：先把材料里的信息读对，再学会要求投研 Agent 把信息记录对、输出得可验收。基础层约35分钟，开发者层约40分钟。

10分钟白话解释

估值模型不是价格测量仪。它更像一台“假设翻译器”：把未来收入、利润、现金和风险的假设，翻译成今天的价值。

当模板、代码和 AI 把生成模型的门槛降得很低，真正稀缺的就不再是“能不能写出一个数”，而是能不能回答三件事：这个数是什么性质、从哪里来、怎样变成结论。

第一层：人能读懂六类信息

信息性质例子正确读法
已发生事实2025年审计收入100亿元已经发生，仍需核对对象、期间、单位和会计口径
公司指引管理层预计2026年收入约120亿元是公司在特定日期作出的前瞻表述，不是已实现事实
外部预测某券商预计2027年收入150亿元是外部观点；单家预测不能冒充市场共识
内部假设Base情景采用2026年收入125亿元是模型作者的选择，必须说明依据、采用日和敏感性
派生计算在该组输入下股权价值为200亿元是输入经过公式得到的结果，必须能复算
分析判断当前输出只能带条件使用是分析者基于证据作出的意见，必须写明理由和边界

市场共识是“明确样本、统计方法和截点下的多家预测汇总”，仍属于外部预测。只拿到一家报告，不能因为它看起来合理就改名为共识。

AI 生成的摘要也不是第七类信息。AI 是处理者：它可以提取事实、转述指引、计算派生值或写出判断。每一句最终仍要回到上面的信息性质。两个模型说法一致，只能说明它们给出了相同答案，不能代替原始证据或独立计算。

专业标注不是一个“可信度分数”

同一句话至少有四个彼此独立的维度。把它们压成一个分数，会让系统无法解释问题究竟出在哪里。

维度回答的问题典型取值不能替代什么
信息性质这句话在表达什么？事实、指引、预测、假设、计算、判断不能说明来源是否可靠
来源身份谁提供了原始信息？公司、交易所、券商、数据库、研究者不能把前瞻指引变成已发生事实
处理状态信息经历了什么处理？原文、提取、标准化、调整、计算、生成不能说明处理结果已经正确
验证状态当前证据做到哪一步？已复核、部分可用、无法确认、明确错误不能直接等同于整份材料的使用等级

例如，“公司公告中的2026年收入指引”可以同时是：来源身份为公司、信息性质为公司指引、处理状态为已提取、验证状态为已核对原文。来源很强，并不会让它变成已实现收入。

第二层：Agent 能记录关键数字身份证

专业系统不能只保存 2026E收入 = 125亿元，至少要让人回答以下问题：

字段要回答的问题
对象 / 证券是发行人整体、A股、H股，还是某个业务分部？
指标 / 数值 / 单位与币种是收入、利润还是现金流；元、万元还是亿元；人民币还是港币？
期间 / 估值日数字属于哪个报告期，资本结构和价格对应哪一天？
信息性质是事实、公司指引、外部预测、内部假设、派生计算还是分析判断？
来源 / 发布日原始文件或数据是谁发布的，什么时候公开？
采用日本次研究在什么时候把它纳入模型？
变换过程是否换汇、年化、调整一次性项目、汇总或重新计算？
证据指针能否回到文件、页码、表格单元格或可复取的数据记录？
验证状态已复核、部分可用，还是无法确认？

字段是否必填应由这个数字参与的结论决定。只要它进入估值、比较、审计意见或对外表述，对象、期间、单位、信息性质、来源、发布时间、采用日、变换和证据指针就不能留给读者猜。缺失值要显式保留为未知，不能静默填零或由 Agent 自动补写。

一个可复核的记录示例：

长河科技｜合并收入｜125亿元人民币｜2026财年
内部Base假设｜采用日 2026-08-17
依据：公司2026-03-28发布的指引120亿元 + 5亿元内部调整
变换：新增产能爬坡调整；尚缺逐项量价桥
证据：年报第42页｜验证状态：部分可用

这里的“来源可靠”“属于公司指引”“已经程序复核”是三件不同的事。来源身份、信息性质和验证状态必须分开保存。

一条关键数字记录至少应通过以下语义校验：

  • value 与 unit 同时存在，百分比、小数和金额不能靠字段名猜测；
  • subject 明确发行人、证券或分部，双重上市公司的价格数据必须落到具体证券；
  • period_end 与 as_of 分开，财务期间不能冒充估值日；
  • source_published_at、adopted_at 与 research_as_of 可比较；
  • 发生换汇、年化、调整或汇总时，保留原值、变换规则和派生值；
  • 派生计算保存输入版本、公式或计算程序版本，不能只保存最终数字；
  • evidence_pointer 能定位到文件、页码、表格单元格或可复取记录，而不是只保存网站首页。

一条完整证据链

原始披露 → 提取值 → 口径调整 → 模型输入 → 计算结果 → 报告表述

任一箭头断开，都要记录断在哪里、影响什么、补什么才能关闭。网址能打开不等于数值可追溯；报告有引用不等于公式已复算；文字很专业也不等于结论有证据。

PIT：只能使用当时已经知道的信息

假设研究时点是2026年3月31日，那么2026年4月20日发布的一季报不能进入3月31日的模型。后来数据可以用于复盘“当时判断得怎样”，但不能伪装成当时已经知道。

投研 Agent 至少要同时检查：source_published_at <= adopted_at <= research_as_of。若时间关系不成立，应返回无法确认或标记未来信息污染，而不是静默使用。

记录验证状态与材料使用等级是两层判断

单条记录的验证状态描述“这个输入目前查到什么程度”；整份材料的使用等级描述“带着现有缺口，这份输出能否继续进入下一步”。两者不能机械一一映射。

记录验证状态最低判定条件下一步动作
已复核原始证据可定位，语义口径明确；如为派生值，已经独立复算可以进入后续分析，仍保留来源和版本
部分可用已确认一部分字段或方向，但存在可能影响结论的缺口限定用途，记录缺口和关闭条件
无法确认证据缺失、不可复取，或口径/时点无法判断不替作者补假设，等待证据或降级结论
明确错误与原始证据、恒等式或可复算结果冲突停止使用受影响结果并修复重算
材料使用等级含义典型条件
可继续使用核心对象、口径、证据和计算足以进入深入研究关键缺口不会改变当前用途，且边界已披露
带条件使用方向或局部内容可参考，但关键缺口仍可能改变结论必须附条件、敏感性或待补证据
停止使用核心对象、时点、计算或方法存在已确认的严重问题修复并重算前不引用核心输出

一条记录“无法确认”不必自动让整份材料停止使用：如果它与当前用途无关，可以隔离。反过来，一条已复核的股价也不能拯救一个现金流公式错误的模型。

AI 与多模型协作的专业边界

多模型可以帮助发现遗漏、提出反例和复核文字逻辑，但它不是独立证据。两个模型可能读取同一份二手资料、继承相同错误，或在同一提示下产生相似叙述。

合格的多模型流程至少区分：

  1. 同源复述：多个模型基于同一材料给出相似答案，只能提高“发现一致表述”的信心；
  2. 独立取证：第二条证据来自不同的原始来源或独立披露，才可能增加证据强度；
  3. 独立计算：派生数值由确定性程序或另一套可检查公式重算，而不是让另一个模型心算；
  4. 分歧保留：模型意见不一致时保存各自依据，不用多数投票覆盖未知。

好坏对照

材料A：

公司2025年审计收入100亿元。管理层于2026年3月28日指引2026年收入约120亿元。Base情景在2026年3月31日采用125亿元，其中5亿元为内部调整，产能爬坡依据尚未闭合。在当前现金流与折现假设下，模型输出股权价值240亿元，计算尚未独立复核。因此当前材料部分可用。

材料B：

公司2026年收入125亿元，市场一致认为价值240亿元，模型已经验证增长能够实现。

A把事实、指引、假设、派生计算、验证状态和使用意见分开。B不仅让条件消失，还把预测写成事实、把计算结果当成现实证明。

开发者层：验收一段投研 Agent 输出

研究时点固定为 2026年3月31日。虚构 Agent 输出如下：

长河科技2025年收入100亿元。市场共识预计2026年收入125亿元；该数字来自华东证券一份报告。公司随后公布的2026年一季报证明需求强劲，因此我们把Base收入上调到130亿元。根据模型，公司股权价值为240亿元，结论已经验证，可以继续使用。

这段话固定埋入五类问题：

  1. 单家预测冒充共识：只有一家券商报告，没有共识的样本、统计方法和截点。
  2. 未来信息污染：研究时点之后发布的一季报不能进入当时判断。
  3. 内部调整无桥接：125亿元上调至130亿元，但没有量、价、产能或口径桥。
  4. 来源无法定位：只写机构名称，没有报告标题、发布日期、页码或证据记录。
  5. 派生价值无法复算：240亿元缺输入、公式、版本和独立计算结果；“已经验证”表述过度。

合格的验收意见是：

当前输出无法确认。先移除研究时点之后的信息；把125亿元改标为单家券商预测并补齐报告证据；将130亿元标为内部假设并给出调整桥；保存估值输入和公式后独立重算。完成前不能声称结论已经验证，也不能推出股票值得买。

负对照：不是所有缺口都等于停用

只会喊「有问题」的验收器，和只会放行的验收器一样没用。同一天的第二份输出：

长河科技2025年审计收入104.3亿元（2025年报第42页）。截至2026年3月20日，8家机构对2026年收入的预测中位数为121亿元，样本与截点见附表B-2。公司2026年3月28日发布的指引为约120亿元，已核对公告原文。Base情景采用125亿元，相对指引的5亿元上调来自三条新产线的爬坡量价桥（附表B-4）。在附表B-6保存的输入与折现公式下，模型输出股权价值228亿元，已由独立脚本重算一致。2027年以后的终值增长采用2%，与行业惯例一致。

这段话里有四处看起来可疑但实际合规：

条款为什么不降级
8家机构中位数121亿元样本家数、统计方法和截点齐全，且标为外部预测而非事实
3月28日公司指引发布日早于研究时点3月31日，PIT 序关系成立，且已回到公告原文
5亿元内部上调调整被单独标出，并给出逐项量价桥和可定位附表
股权价值228亿元输入、公式和独立脚本重算都在；注意「独立脚本重算」才算数，「另一个模型也这么说」不算

真实缺口只有一处：终值增长2%的依据是「行业惯例」，没有数据来源、样本或口径，属于证据指针缺失。

因此这段输出的等级是带条件使用，不是无法确认。缺口已知、可隔离、不改变当前用途的方向，就限定用途继续用；把它也判成停用，等于告诉下游「你的验收器无法区分严重性」。

这条对偶必须和「什么时候返回无法确认」一起记：知道何时不该报警，和知道何时必须报警，是同一项能力的两半。

修复后的最小记录链

环节修复后应保存什么
外部预测华东证券报告标题、发布日期、页码、125亿元原文；性质标为单家券商预测
内部假设130亿元、采用日、相对125亿元的5亿元调整，以及量价/产能桥
PIT移除3月31日之后发布的一季报；另存为事后复盘证据
派生计算估值输入版本、公式或程序版本、运行结果与独立重算状态
分析判断当前用途、使用等级、关键缺口、关闭条件和仍不能断言的内容

修复并不等于把所有字段填满。无法获得的内容应继续标为未知；只有证据真正补齐或计算真正重跑，状态才能升级。

失败状态矩阵

触发条件Agent 应返回禁止行为
只有一家预测却被命名为共识单家外部预测；共识无法确认自动补出“市场一致预期”
发布日晚于研究时点未来信息污染静默回填历史研究
调整后数字没有逐项桥内部假设，部分可用或无法确认把调整后值写成公司事实
来源只能定位到网站首页或机构名称证据指针缺失用“来源可靠”代替定位信息
派生值缺输入、公式或重算尚未程序复核写成“已经验证”
原始证据与记录值直接冲突明确错误用语言模型多数票覆盖冲突
外部预测已写明样本家数、统计方法和截点外部预测，不降级因为出现「共识」二字就自动降级
发布日早于研究时点且证据可定位状态不变因为材料里出现了日期就报时点穿越

正反验收测试

正例测试：给定公司公告、研究时点和一条内部调整，Agent 应保留公告原文与指引性质，把内部调整单独记录，输出派生值时附输入与公式，并把未闭合部分标为部分可用。

反例测试：把同一公告发布日期改到研究时点之后，Agent 必须拒绝将其用于当时模型；删除报告页码后，证据状态必须降级；删除估值公式后，系统不得继续显示“已复核”。

回归测试：上游输入、单位、币种、股本或研究时点发生变化时，派生值与最终表述必须重新生成，不能保留旧数字或旧验证状态。

练习：写一条验收测试

读懂失败矩阵不等于会写测试。一条验收测试至少要写清三件事，其中第三列最常被漏掉：

变更（输入怎么改）Agent 必须返回什么什么必须不变
把券商报告发布日从3月20日改到4月20日未来信息污染；该预测退出3月31日模型输入2025年审计收入、公司指引和已复算的派生值状态
删除估值输入文件中的折现率字段派生值降级为尚未程序复核上游事实与外部预测的验证状态，以及证据指针
把「8家机构中位数」改写为「市场一致预期」，其余不动
把年报引用页码从第42页改成第43页，数值仍可在第43页定位
把收入单位从「亿元」改成「万元」，数值不变

第三列是回归测试的本体，也是防误报的训练：它逼你说出这次变更不应该波及什么。一个把每次变更都当成全局降级的 Agent，通不过任何一条第三列。

写完后展开参考答案

第3行：应返回「单家/汇总口径被改写，共识命名无法确认」——样本、方法和截点没有变，但表述把可质证的汇总换成了不可质证的命名。不变的是：底层8家预测值、截点日期，以及派生计算的状态。

第4行：状态不变，不降级。证据仍可定位，指针只是更精确了。这一行的正确答案就是「什么都不该发生」；如果你的系统在这里报警，它会在真实项目里天天误报。

第5行：应返回明确错误——单位与数值必须同时改，否则记录自相矛盾。受影响的是全部派生计算，必须重算；不变的是信息性质、来源身份、发布日和采用日，它们和单位错误无关。

参考答案不唯一。判分看三点：是否给出了具体的失败状态而不是「报错」，是否写了第三列，以及有没有把第4行也判成降级。

一页验收清单

  • 六类信息是否逐项标注，没有把预测、假设和输出写成事实？
  • 信息性质、来源身份、处理状态和验证状态是否分开？
  • 对象、证券、期间、估值日、单位和币种是否明确？
  • 每个关键输入能否回到原始证据，证据是否在研究时点可得？
  • 每次换汇、年化、调整、汇总和计算能否重放？
  • 单家预测是否被错误命名为市场共识？
  • AI 或多模型一致是否被错误当成独立证据？
  • 派生数字是否经过确定性程序或可检查公式复算？
  • 未知、部分可用和明确错误是否有不同处理？
  • 合规条款是否被误判成问题，把「谨慎」当成了「什么都降级」？
  • 最终意见是否写明用途、影响、关闭条件和仍不能断言什么？

投研 Agent 开发的最低能力

完成这一层后，你至少应该能够：

  • 为关键数字定义可追溯的记录契约；
  • 从报告表述反查到原始证据和每一步变换；
  • 阻止研究时点之后的信息污染当时判断；
  • 区分证据、计算、推断、判断和未知；
  • 要求派生数字由独立计算复核，而不是由另一个模型复述；
  • 为来源缺失、口径不明、时间穿越和无法复算设计失败状态与测试。
  • 为「不该降级」的情况同样设计测试，避免验收器沦为无差别报警器。

这叫“估值系统开发者 / 验收者”水平。它不要求你已经能覆盖一个行业多年，也不要求你给出目标价、评级或买卖建议。

交给后面几课

本课定义的失败状态和记录契约，只有被后面几课复用才不是挂件。第2到第7课的每个失败模式——错股本、错时点、利润不等于现金、峰值永久化、隐藏终值、方法错配——最终都要能落到一个失败状态和一条验收测试上。学后面几课时，每发现一个新错误就问：它触发哪个状态，我要用什么变更把它测出来，以及这次变更不应该波及什么。

闯关

  1. “2027年利润30亿元，来源：某券商报告。”应标为什么？
    • A. 已发生事实
    • B. 单家券商预测
    • C. 公司指引
  1. 研究时点为2026年3月31日，Agent引用4月20日发布的一季报支持当时的收入假设。最准确的问题是什么？
    • A. 来源是公司公告，所以可以使用
    • B. 出现未来信息污染，必须从当时输入中移除
    • C. 只要另一个模型同意就可以使用
  1. Agent给出240亿元股权价值，有引用但没有保存输入、公式和重算结果。最合适的状态是：
    • A. 已验证
    • B. 无法确认，补齐计算链后再判断
    • C. 引用存在即可继续使用
完成后展开答案
  1. B。来源于一家机构不等于市场共识，更不等于事实。
  2. B。原始来源再可靠，也不能穿越研究时点。
  3. B。引用只能证明材料来源，不能证明派生计算正确；必须保存输入、公式和独立重算结果。
