第5天：反向 DCF

本课目标：把当前价格翻译成带条件的经营要求，理解多组解、口径一致和经济不可行区。基础计算约35分钟，进阶检查约20分钟。

打开本课互动HTML

先闭卷回忆

不看第4课，写下最小DCF的六个输入：起点现金流、增长、显性期、永续增长、折现率和________。

再回答：如果当前市场股权价值高于模型基准价值，要在其他条件不变时解释它，通常需要更强还是更弱的经营假设？

10分钟白话解释

正向DCF从假设走向价值：

经营预测 → FCFF → 折现 → EV → 股权价值

反向DCF把问题倒过来：〔D5-S1〕

当前股权价值 → 对应EV → 所需FCFF → 所需增长、利润率或持续时间

它不预测未来，也不读取市场参与者脑中的统一答案。它只是说：在指定模型约定下，要让公式等于当前价格，某个经营变量必须达到什么水平。

因此反向结果必须是一条条件句：

在WACC 9%、显性期7年、永续增长2%、净债务20亿元和本课FCFF定义下，300亿元股权价值要求显性期FCFF年增长约16.25%。

删掉任一条件，“16.25%”就像失去单位的数字，无法解释。专业材料可以把这个数字称为价格隐含增长率；那是模型条件下的 implied growth，不是市场共识。〔D5-S3〕

先对齐股权价值和EV

本课命令接收的是当前股权价值300亿元。模型内部仍要经过资本结构桥：

目标EV = 目标股权价值 + 净债务
       = 300 + 20
       = 320亿元

如果输入本来就是EV，却再次加净债务，反解会要求不必要的高增长。反向DCF首先要继承正向模型的对象、单位、币种、FCFF和EV桥。

完整示例：300亿元要求什么

第4课基准模型的股权价值是184.09亿元，当前教学股权价值设为300亿元：

差距 = 300 ÷ 184.09 - 1 = 63.0%

“市场比模型高63%”不等于市场错误，也不等于公司必须增长63%。价值由多年的现金流和终值共同决定，需要让求解器在保持其他输入不变时寻找增长率。

固定其他条件，只反解增长

WACC所需显性期年增长
7%9.68%
8%13.14%
9%16.25%
10%19.11%
11%21.78%

同一个300亿元，在WACC 7%时要求增长9.68%，在11%时要求21.78%。变化的不是公司现实增长，而是模型对未来现金要求的折现约定。

固定增长，只反解起点FCFF

WACC所需起点FCFF相对10亿元基准
7%11.02亿元+10.2%
8%13.33亿元+33.3%
9%15.68亿元+56.8%
10%18.06亿元+80.6%
11%20.46亿元+104.6%

16.25%增长和15.68亿元起点FCFF是两条不同解释路径。它们都不是市场共识，只是在分别固定其他变量后得到的条件解。

第三条路：不提高增长，只延长时间

前两条路都在提高“每年多少现金”。还有一条常被忽略的路：现金流一分不多，只是高增长持续得更久。

保持起点FCFF 10亿元、增长8%、WACC 9%、永续增长2%和净债务20亿元全部不变，只延长显性期年数：

显性期年数股权价值
5年167.79亿元
7年184.09亿元
10年207.98亿元
15年246.35亿元
20年282.99亿元
23年304.18亿元

要用这条路解释300亿元，需要8%的增长维持约23年（22年只到297.18亿元）。

把三条路并排看：

解释路径这个价格要求什么要去质证什么
提高增长七年内年增长16.25%公司历史、同行、产能爬坡
提高起点起点FCFF 15.68亿元（+56.8%）当前FCFF是否被低估，是否有一次性因素
延长时间8%增长维持约23年竞争壁垒能否抵挡23年的均值回归

同一个300亿元，三个完全不同的经营故事。这就是“不存在唯一隐含观点”的具体含义——不是一句免责声明，而是可以逐条算出来的三张不同答卷。

可填写的完整计算工作表

不看上文，把反解的准备工作重新做一遍：

步骤输入或公式你的结果
1. 正向基准股权价值第4课结果______
2. 目标股权价值本课给定______
3. 差距步骤2 ÷ 步骤1 - 1______
4. 目标EV步骤2 + 净债务20______
5. 你预测的所需增长（WACC 9%）先猜，再运行脚本______
6. 脚本给出的所需增长运行后填写______

前四格应依次为184.09亿元、300亿元、+63.0%和320亿元。第5、6格的差距本身就是有用信息：多数人第一次会低估所需增长，因为直觉上把“价值高63%”想成“增长高一点点”，忽略了终值同时被抬高。

第4格最容易错。 如果你写成300亿元或280亿元，先回第2课的第二座桥：反解的目标必须是EV，而输入给的是股权价值。

为什么不存在唯一隐含观点

下面的调整都可能提高模型价值：

  • 起点FCFF更高；
  • 收入增长更快；
  • 利润率更高；
  • 现金转化更好；
  • 高增长维持更久；
  • WACC更低；
  • 远期状态更强。

真实价格可能由这些变量的无数组合解释。专业反向DCF至少展示一条曲线或多组组合，并明确一次只反解了哪个变量。

从数学答案回到经营问题

得到16.25%以后，研究才刚开始：

质证方向要问什么
历史公司过去是否在相同基数和周期位置实现过？
同行可比业务是否做到过，口径和周期是否一致？
产能销量增长是否需要新产能，何时投产？
价格与份额增长来自涨价、行业扩张还是抢份额？
再投资Capex和营运资金是否支持增长，FCFF定义是否仍成立？
持续时间16.25%需要维持七年，还是只维持两年？

反向DCF把“贵不贵”的争论改写成可取证问题，但不替你回答这些问题。

三种“无解”不要混在一起

类型含义正确动作
公式无效如WACC不高于永续增长修正模型约定，不打印伪结果
搜索范围无解求解器只搜索到100%增长，目标仍在范围之外检查范围、单位、对象和EV桥；如扩大范围必须披露
经济不可行数学能解，但要求长期利润率超过100%或产能远超物理上限标记该组约定下缺乏经济可行解释

不能为了得到一个可打印数字就不断放宽边界。无解本身是诊断信息；同时也要先排除把万元当亿元、把EV当股权价值等基础错误。

好坏对照

合格输出：

在本课FCFF定义、净债务20亿元、7年显性期、2%永续增长下，300亿元股权价值在WACC 7%—11%时要求FCFF年增长约9.68%—21.78%。基准WACC 9%对应16.25%。同一价格也可由起点FCFF提高至15.68亿元，或由8%增长维持约23年解释；本报告一次只反解一个变量。下一步需与公司历史、产能、再投资和现金转化比较；该区间不是市场共识，也不证明公司能够实现。

不合格输出：

市场隐含公司未来增长16.25%，因此低于这个预测就是悲观，高于就是乐观。

后一段的问题不是用了“隐含”这个词，而是删掉了全部模型条件，又把一条单变量条件解写成市场统一观点。专业材料可以把市场价格代回模型，写出带条件的价格隐含增长率；〔D5-S3〕 那才是 implied growth 的合法用法。

单变量实验：先预测，再求解

  1. 目标股权价值仍为300亿元，只把WACC从9%升至10%，隐含增长怎样变化？
  2. WACC仍为9%，只把目标股权价值降低，隐含增长通常怎样变化？
  3. 数学解出长期EBIT利润率110%，是否应把110%当普通预测写入Base？
  4. 输入的300亿元本来就是EV，模型仍按股权价值再加20亿元净债务。反解结果怎样偏？
完成后展开答案
  1. 从16.25%升至19.11%。折现要求更高，需要更强现金流才能解释同一价格。
  2. 通常下降；需要解释的价值更低。实际方向仍应由同一公式复算。
  3. 不应。应标为该组约定下的经济不可行区，并检查对象、口径和模型选择。
  4. 目标EV被错误抬高到340亿元，求解器会要求更高的增长。方向永远是“要求被抬高”，因为净债务为正；如果是净现金公司，同样的错误会让要求被压低。

口径一致检查

正向模型若逐年使用：

FCFF = EBIT × (1 - 税率) + D&A - Capex - 营运资金增加

反向模型却改用“收入 × 利润率 × 80%固定转化率”，正向情景增长与反向隐含增长就不在同一根轴上。0.80不一定错，问题是口径切换没有解释和敏感性。

检查反向DCF时至少对齐：估值对象、股权价值与EV、现金流定义、税率、显性期、终值、折现时点和WACC。

负对照：要求很高不等于材料有问题

只会看“隐含增长21.78%太离谱了”就降级的检查器，其实是在用自己的直觉替代材料的披露质量。读下面这段输出：

在本课FCFF定义、净债务20亿元、7年显性期、2%永续增长和WACC 11%下，当前300亿元股权价值要求显性期FCFF年增长21.78%。本表同时给出WACC 7%—11%的完整曲线（9.68%—21.78%），并说明本次只反解增长率一个变量，其余输入固定为正向模型取值。正向与反向使用同一套FCFF定义，见附表E-1。该要求尚未与公司历史、产能和再投资能力比较，因此本报告不判断它能否实现。

这段材料里有三处看起来危险但不应自动降级：

表面信号为什么当前不降级
隐含增长高达21.78%它是WACC 11%这一格的条件解，曲线两端都已披露；高不等于错，反而说明折现约定被如实传导
反解结果没有配一个“合理/不合理”的结论材料明确写了尚未质证，这是边界披露，不是缺失结论
只反解了一个变量已声明“本次只反解增长率”，读者知道这不是唯一解释路径

真实缺口可能仍然存在——比如没有展示起点FCFF或持续时间这两条替代路径。但那是一条具体的完整性建议，不是“数字太高”这种直觉报警。

知道何时不该报警，和知道何时必须报警，是同一项能力的两半。

进阶检查：把反解问题写成失败状态

失败状态矩阵

第二列统一使用第1课的记录验证状态（已复核 / 部分可用 / 无法确认 / 明确错误）加材料使用等级。cases/00-basics 和 分层审计清单 里的“通过 / 警告 / 失败”是清单项状态，粒度不同，两套词不要混着写。

触发条件记录验证状态 + 使用等级影响还不能断言
输入本来是EV，模型仍按股权价值再加净债务明确错误；停止使用反解结果目标EV被抬高，所需增长被系统性高估正向模型的EV桥也一定错
反解结果只报单点，不披露WACC、显性期和终值约定无法确认；该结果停止使用数字失去条件，无法解释也无法复算该单点数值一定算错
反解结果被命名为“市场共识”，但没有调查样本、统计口径和截点明确错误（性质错标）；表述停止使用模型条件解被伪装成调查汇总市场参与者一定不这样想
只写“市场隐含增长16.25%”，省略 WACC、终值、现金流定义和单变量约束无法确认；该表述停止使用数字失去条件，无法解释也无法复算该单点数值一定算错
写成“价格/市场隐含要求”，并披露完整模型条件状态不变，不降级这是带条件的 implied growth，专业材料允许这样写该要求一定能实现
正向与反向使用不同FCFF定义，且未解释或桥接无法确认（口径不一致）；跨口径比较停止使用两个增长率不在同一根轴上，数值接近也不能互证哪一边更接近现实
求解器返回无解，作者不断放宽搜索范围直到打印出数字明确错误；该结果停止使用无解这条诊断信息被抹掉该价格一定无法被任何假设解释
数学解出长期利润率超过100%或产能超物理上限，仍写入Base明确错误（经济不可行区当普通预测）；停止使用该情景情景失去经济含义当前价格一定不合理
只展示一条解释路径，未说明是否存在替代组合部分可用；结论带条件使用读者可能把一条条件解误读为唯一解其他路径一定更合理
隐含要求很高，但曲线、变量范围和固定条件都已披露状态不变，不降级按条件句继续使用并去质证要求高一定意味着高估
材料写明“该要求尚未与历史和产能比较，本报告不判断能否实现”状态不变，不降级这是边界披露，正是本课要求的表述不给结论等于分析不完整

练习：写一条验收测试

变更（一次只改一个条件）Agent 必须返回什么什么必须不变
把输入的300亿元从“股权价值”改标为“EV”，模型内部逻辑不动
删除输出中的WACC字段，只保留“隐含增长16.25%”
把反向模型的现金流定义换成“收入×利润率×80%”，正向不动
把输出标题从“本模型条件下的隐含要求”改成“市场一致预期”

写完后展开参考答案

第1行：应返回明确错误——目标EV被重复加了20亿元净债务，变成340亿元，所需增长被高估。受影响的是全部反解结果；不变的是正向模型的184.09亿元及其上游输入状态。

第2行：应返回“无法确认”，16.25%失去模型条件后不可解释、不可复算。注意数值本身没有算错，缺的是条件；不变的是正向模型和输入记录的验证状态。

第3行：应返回“口径不一致，无法确认”，正向增长与反向隐含增长不能直接比较，即使两个数字碰巧接近。不变的是各自内部的计算正确性——两边都可能各自算对，错的是把它们放在同一张图上。

第4行：应返回明确错误（信息性质错标）——把派生计算改标成了外部预测的汇总。受影响的只有表述层；不变的是全部数值、公式和输入状态。这一行的重点是：一个字都没改数字，性质错标依然是明确错误。

第5行：状态不变，不降级。补充替代路径没有改变任何已有结果，只是让“不存在唯一隐含观点”这句话变得可验证。这一行的正确答案是「什么都不该变坏」。

判分看三点：是否给出具体状态，是否分清了“数值错”与“条件缺失/性质错标”，以及有没有把第5行判成需要重新审查。

一页验收清单

这张清单是 分层审计清单 第二层 D7、D8、D15 在本课的展开；括号里是清单编号。

  • 反解的目标是股权价值还是EV，资本结构桥有没有被重复计算？（D8）
  • 正向与反向是否使用同一套FCFF定义，切换口径是否解释并给了敏感性？（D7）
  • 输出是否带全模型条件：WACC、显性期、永续增长、净债务和现金流定义？（D15）
  • 是否说明这一次只反解了哪一个变量？（D15）
  • 是否展示曲线或至少两条替代解释路径，而不是单点？（D15）
  • 超过100%利润率或超物理上限的解，是否被标为经济不可行区而不是普通预测？（D15）
  • 出现无解时，是记录为诊断结果，还是通过放宽边界抹掉了？（D15）
  • 没有调查样本、统计口径和截点时，是否仍把反解结果写成“市场共识”？

  1. 输入300亿元本来是EV，模型却按股权价值再加20亿元净债务。最可能结果是：
    • A. 反解要求被抬高
    • B. 没有影响
  1. 反解无经济可行解释时，正确做法是：
    • A. 记录无解区域，并检查对象、口径和模型约定
    • B. 不断放宽假设直到得到可打印数字
  1. 正向与反向模型使用不同FCFF定义，但结果数字接近。可以自动通过吗？
    • A. 可以，结果接近即可
    • B. 不可以，先统一或桥接口径再比较
  1. 同一个300亿元既可由“7年16.25%增长”解释，也可由“8%增长维持23年”解释。这说明：
    • A. 其中必有一个是错的
    • B. 反解一次只固定其他变量求一个解，替代路径本来就存在
    • C. 应取两者平均作为市场预期
  1. 一份反解材料写着“该要求尚未与公司历史和产能比较，本报告不判断能否实现”。应如何处理？
    • A. 结论不完整，降级
    • B. 状态不变；这是必须有的边界披露
完成后展开答案
  1. B。它是模型条件下的要求，不是调查得到的共识。
  2. B。现实没有改变，改变的是折现约定。
  3. A。目标EV被错误增加20亿元，求解器会要求更多现金流。
  4. A。无解是诊断结果，不应被静默抹掉。
  5. B。数值偶然接近不能修复定义错位。
  6. B。两条路径都是合法的条件解，对应完全不同的经营故事和完全不同的取证方向。C 制造了一个谁也无法复算的新数字。
  7. B。写明尚未质证是诚实，不是缺失。把边界披露当成缺陷，会训练出一个奖励过度自信表述的验收器。

本课边界

你现在能把价格翻译成一组可质证的经营要求，能同时给出增长、起点和持续时间三条解释路径，并识别多解、口径错位和经济不可行区。反向DCF不证明公司能或不能实现要求，也不直接回答证券是否值得买。

本课不交付新的失败模式——六个模式里的错时点、错股本、利润不等于现金、峰值永久化、隐藏终值和方法错配分别由第2、3、4、6课交付。本课交付的是条件句表述纪律：任何反解数字，只要脱离模型条件就不能使用。
