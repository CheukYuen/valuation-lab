GRADUATION

学完能做什么

给你一份模型摘要或研报，你能够：

  • 确认估值对象、时点、单位和每股分母
  • 把事实、外部预测、内部假设和模型输出分开
  • 检查利润如何变成现金
  • 找到控制结果的关键假设和终值
  • 判断方法与商业模式是否匹配
  • 给出可继续使用 / 带条件使用 / 停止使用，并说明证据

这不代表你已经会独立估值，也不代表你能据此决定买卖。

SCOPE

这门课明确不做什么

这些边界来自项目设计，不是能力不足——它们划清了"判断力训练"和"投资建议"的界线。

不产出投资结论

不给目标价、评级、仓位或买卖动作。所有结论必须可复算：改输入重跑，不靠记忆里的数字。

危险信号不等于模型错误

危险信号只是筛查线索。必须同时说明为什么可疑、影响是什么，以及还不能断言什么。

六类信息不互相冒充

已发生事实、公司指引、外部预测、内部假设、派生计算和分析判断各是各的；市场共识仍属外部预测。答案文件也只记录缺陷和方向区间，不记录单一"正确数值"。

案例冻结后不再改动

练习案例一旦冻结就不再更新，来源仓库后续变化不会同步回来，保证你的判断可复现。
