GRADUATION

学完能做什么

完成课程后，你能够：

  • 从 EBIT 走到 FCFF、企业价值、股权价值和每股价值
  • 运行并解释一个最小 DCF，说明关键假设和敏感性
  • 确认估值对象、时点、单位和每股分母
  • 把事实、外部预测、内部假设和模型输出分开
  • 检查利润如何变成现金
  • 找到控制结果的关键假设和终值
  • 判断方法与商业模式是否匹配
  • 给出可继续使用 / 带条件使用 / 停止使用，并说明证据

这代表你能完成和检查一套简化估值，不代表你已经能够独立预测真实公司的全部未来，也不代表你能据此决定买卖。

SCOPE

这门课明确不做什么

教学计算可以得到企业价值、股权价值和每股价值；下面的边界划清教学练习与现实投资建议。

教学估值不是投资建议

练习可以计算明确假设下的每股价值，但不给现实证券目标价、评级、仓位或买卖动作。所有计算必须可复算。

危险信号不等于模型错误

危险信号只是筛查线索。必须同时说明为什么可疑、影响是什么，以及还不能断言什么。

六类信息不互相冒充

已发生事实、公司指引、外部预测、内部假设、派生计算和分析判断各是各的；市场共识仍属外部预测。基础题可以有明确答案，真实案例要说明情景和不确定性。

案例冻结后不再改动

练习案例一旦冻结就不再更新，来源仓库后续变化不会同步回来，保证你的判断可复现。
