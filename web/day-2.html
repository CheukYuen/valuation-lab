从经营利润走到每股价值 · 第 2 课

亲手打通价值桥

利润不是现金，企业价值也不是每股价值。今天亲手从 EBIT 走到 FCFF、股权价值和每股价值，并与财报现金流交叉检查。〔D2-S1〕

一句话速览

任何一座桥断掉，最后的每股数字都可能失真。不要替作者脑补中间项。

01 · 先记住结构

只记两座桥

第一座桥回答经营利润最后留下多少现金；第二座桥回答经营资产的价值中，有多少真正属于对应的普通股股东。

EBIT − 经营税 = NOPAT + 折旧 − Capex − 营运资金增加 = FCFF

EV + 现金 − 债务等 = 股权价值 ÷ 正确股本 = 每股价值

检查原则：模型从利润直接跳到价值，或从 EV 直接跳到每股价值时，要让材料把桥写出来。

04 · 负对照

危险信号不等于自动报错

Capex 12亿元、营运资金为负、同时出现三种股本——看起来危险，但用途写清、公式扣对时不该降级。

当前不降级

高Capex有逐项用途并已在FCFF中扣除；负数营运资金被明确为释放现金；10.5亿 / 10亿 / 8亿各有用途。

会误报的检查器

见到“Capex高”“出现负数”“股本数字不止一个”就报警。验收器必须同时会抓错误和放过合规条款。

有总股本和流通股两种口径，且各自用途解释清楚状态不变，不降级按各自用途继续使用多种股本数字天然冲突

def fcff(p):
    nopat = p["ebit"] * (1 - p["tax_rate"])
    return {
        "nopat": nopat,
        "fcff": nopat + p["depreciation"] - p["capex"] - p["working_capital_increase"],
        "skipped_reinvestment": p["capex"] + p["working_capital_increase"] - p["depreciation"],
    }

def equity(p):
    return {"equity_value": p["ev"] + p["cash"] - p["debt"] - p["lease_liability"]
            - p["minority_interest"] + p["non_operating_assets"]}

def per_share(p):
    basic = p["total_shares"] - p["treasury_shares"]
    return {"per_share_basic": equity(p)["equity_value"] / basic}

10 · 本课边界

现在能解释什么，还不能决定什么

✓
现在可以

解释利润怎样变成现金、EV 怎样变成每股价值，并写出包含“必须改变”和“必须不变”的验收测试。

—
还不可以

仅凭这座桥判断预测是否合理，或由每股输出推出股票是否值得买。
